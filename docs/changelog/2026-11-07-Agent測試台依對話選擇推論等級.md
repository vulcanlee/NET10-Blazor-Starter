## 目的

《AI Agent PRD》§十只剩最後一項規劃中需求：在 Agent 測試台畫面上依對話選擇推論等級。

0.9.168 起推論等級已經可以在系統參數依功能設定，但想「這一題讓它想久一點」時，還是得請管理員改系統參數，而且會影響所有人。

## 使用者的決定（2026/11/07）

| 項目 | 決定 |
|---|---|
| 可選時機 | 隨時可改，下一則訊息起生效；前面的對話照樣帶著 |
| 接續舊對話 | 記住那段對話上次選的；舊對話沒存過的視為「系統預設」 |
| 適用頁面 | 只有 Agent 測試台（系統管理助理仍由系統參數統一設定） |

## 內容

- **畫面**：對話區上方新增「推論等級」下拉選單。
  - 第一項「系統預設（目前：…）」，括號裡是系統參數或設定檔目前會送的值；沒有設定時是「不指定，由模型決定」。
  - 後面是 none、low、medium、high、xhigh。
  - 回覆中或等待核准時停用；「新對話」回到系統預設；從「我的對話」接續時顯示那段對話存的值。
- **優先順序**：由高到低取第一個有值的。
  1. 這段對話選的（`AiCallContext.ReasoningEffortOverride`）。
  2. 系統參數「Agent 測試台的推論等級」。
  3. `AiSettings:AgentReasoningEffort`。
  4. 都沒有就不送。
- **對話**：
  - `AiAgentRunner.StartAsync(definition, reasoningEffort)` 帶入開對話時選的值。
  - `AiAgentChat.SetReasoningEffort` 用同一個 session 重建 agent，前文照樣帶著；模型沿用開對話時的（`AiCallContext.ModelOverride`）。不認得的值丟 `ArgumentException`，執行中或等待核准時丟 `InvalidOperationException`。
- **保存**：
  - 存進對話內容的新欄位 `AiAgentConversationContent.ReasoningEffort`。照既有「只加不改」的慣例，SchemaVersion 不變，舊檔讀出來是 null。
  - 接續時沿用；存的值不合法時當作系統預設，並記警告。
- **錯誤訊息**：模型拒絕對話選的值時，顯示「此模型不接受推論等級「none」（這段對話選的推論等級），請在對話上方改選其他等級或「系統預設」。」。來源種類改成三種（`AiReasoningEffortOrigin`）。
- **系統參數**：「Agent 測試台的推論等級」的說明補上：使用者在畫面上替某段對話選了推論等級時，以畫面為準。
- **不寫稽核**：這只是對話的偏好，實際送出的值在 AI 對話紀錄的原始請求裡看得到。

## 獨立審查

另派一個代理人只看程式差異，結果沒有高嚴重度問題。處理如下：

| 發現 | 處理 |
|---|---|
| 管理員在對話途中改了模型，使用者只改推論等級，重建的 agent 會悄悄換成新模型，畫面上的「使用模型」卻還是舊的（中） | `AiCallContext` 加 `ModelOverride`，只改推論等級時沿用開對話時的模型（`ModelName`）；系統管理助理每輪規劃換模型的既有行為不變。新增測試 |
| 重建 agent 時若丟出其他例外（例如對話途中 AI 設定被改壞）會往上拋，可能讓整個連線斷掉；提示文字也會誤導（低） | 狀態不允許時照舊提示等回覆結束；其他例外記 Error、以一般錯誤提示，對話維持原本的推論等級 |
| 改值失敗退回舊值時，下拉選單可能不會重新同步（低） | 退回時換 `@key` 強制重新渲染 |
| 「系統預設（目前：…）」顯示的是系統參數現在的值，已開著的對話可能還在用開對話時的值（低） | 不改：只是顯示；改推論等級或開新對話時就會用到現在的值 |
