# 對話窗頁尾順序定案（0.10.19）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.10.19
- 首次實作版本：0.10.19
- 最後核對日期：2026/11/14

## 目的

[升級 .NET 11](2026-11-14-升級NET11.md)（0.10.14）時，AntDesign 1.6.3-dotnet11.rc3 把對話窗的預設頁尾改成先「取消」再「儲存」（PR #4857，對齊 antd）。當時以樣式暫時維持原本的「儲存　取消」，並註明「等使用者決定要不要採用新順序」。

## 決定

使用者 2026/11/14 決定**維持「儲存　取消」**，不採用新順序。使用者已經看慣原本的順序。

## 變更內容

- 畫面與行為沒有改變：`Commons/OverlayStyles.razor` 的 `.ant-modal .ant-modal-footer { flex-direction: row-reverse; flex-wrap: wrap; }` 照舊保留，`ModalFooterOrderTests` 照舊守門。
- 把「等使用者決定」改成「使用者 2026/11/14 決定維持」：`OverlayStyles.razor` 與 `ModalFooterOrderTests` 的註解、速查表 §6.33 第 124 點、對話窗 UI 設計規範、測試指南。
- 歷史紀錄（升級 .NET 11 的變更紀錄與測試報告）保留當時的寫法。

## 仍要注意

- 對話窗**只能用預設頁尾或 `Footer="null"`**，不可以自訂頁尾內容，否則會被一起反轉。
- 只有畫面順序反轉：畫面上先「儲存」，DOM 與按 Tab 的順序仍是先「取消」。

## 版本

改了 `.razor` 與測試檔的註解，屬建置內容，版本 0.10.18 → 0.10.19。
