## 目的

《AI Agent PRD》§十 的已知限制：推論等級只有一個全域設定 `AiSettings:AgentReasoningEffort`，所有 Agent 功能共用，而且只能改設定檔。
想讓定時巡檢省一點、讓工作流程想周全一點，都做不到。

## 使用者的決定（2026/11/07）

| 項目 | 決定 |
|---|---|
| 適用功能 | 只有 Agent 類功能（走 Responses API）：Agent 測試台、專案狀態報告、多觀點審查、系統管理助理 |
| 定時巡檢 | 和系統管理助理共用（跟模型設定一樣） |
| 測試台畫面上依對話選擇 | 這次不做，留在 PRD 規劃中需求 |
| 實機驗證 | 用真的 AI 金鑰（不印出金鑰） |

AI 日誌分析、AI 例外分析、系統管理助理的分派判斷（Chat Completions）維持不送推論等級。

## 內容

### 新設定 `AiReasoningSettings`

- 四個鍵：`AgentPlayground`、`ProjectStatusReport`、`MultiPerspectiveReview`、`AdminAssistant`，預設空字串。
- 鍵名和 `AiModelSettings` 的同名鍵一致，以 `AiCallContext.ModelKey` 對應，呼叫端不用改；定時巡檢用系統管理助理的定義，自然沿用 `AdminAssistant`。
- **空白＝沿用 `AiSettings:AgentReasoningEffort`**（全域值仍只在設定檔，預設 `null`＝不送，由模型決定）。
- 驗證：`AiReasoningSettingsValidator`，只接受空白或 `none`、`low`、`medium`、`high`、`xhigh`（不分大小寫），啟動時檢查。
- 不放進 `AiModelSettings`：它的 `OverriddenModels()` 會把每個 string 屬性都當成模型名稱，拿去檢查費率。

### 送出與錯誤訊息

- `AiAgentFactory.CreateAgent` 每次建立 agent 時讀取：功能有設定就用它，否則用全域值；仍只在走 Responses API 時送 `reasoning.effort`。
- 模型拒絕時（400 `reasoning.effort`），訊息指名實際用到的設定：
  - 功能自己的值：「此模型不接受推論等級「none」（系統參數「Agent 測試台的推論等級」），請改為空白或此模型接受的值。」
  - 沿用全域值：「此模型不接受推論等級「none」（AiSettings:AgentReasoningEffort 的設定值），請改為 null 或此模型接受的值。」

### 「系統參數」頁

- 系統參數新增「限定選項」的文字參數：`SystemParameterDefinition.AllowedValues`。
  - 存檔時空白可以，其他值不分大小寫比對，存成清單裡的寫法；清單外的值顯示「只接受空白或 none、low、medium、high、xhigh。」。
  - 修改窗用下拉選單，第一項是「（空白：沿用 AiSettings:AgentReasoningEffort）」；目前值為空白時也顯示這段說明。
  - 系統管理助理查系統參數（`get_system_parameters`）時，也看得到可填的值（`allowedValues`）與空白的意義（`blankMeaning`）。
- 「AI 模型」分類新增 4 個參數，各自緊接在同一功能的「使用模型」後面：
  - 「Agent 測試台的推論等級」
  - 「「專案狀態報告」工作流程的推論等級」
  - 「「多觀點審查」工作流程的推論等級」
  - 「系統管理助理的推論等級」（含定時巡檢）
- 系統參數 57 → 61 個。
- 生效時機：Agent 測試台在開對話或接續時建立 agent，所以是下一段新對話（或從「我的對話」接續）起；系統管理助理每則訊息都重建，下一則訊息起；工作流程下一次執行起；定時巡檢下一次巡檢起。

## 獨立審查

另派一個代理人只看程式差異，結果沒有高嚴重度問題。處理如下：

| 發現 | 處理 |
|---|---|
| 「Agent 測試台的推論等級」生效時機寫成「下一則訊息起」，但測試台沒有規劃器，agent 只在開對話或接續時建立，已開著的對話會繼續送舊值（中） | 改成和「使用模型」一樣：「下一段新對話或從「我的對話」接續時」，操作說明、PRD、設定說明同步。新增測試 |
| 系統管理助理查系統參數時看不到可填的值，可能填「高」這類值被拒後才知道（低） | `get_system_parameters` 輸出加上 `allowedValues`、`blankMeaning`。新增測試 |
| 功能有自己的值、但系統參數目錄找不到對應項時，錯誤訊息會指向全域設定（低；目前有守門測試，實際碰不到） | 改成指名 `AiReasoningSettings:{功能}` |
| `AiReasoningSettings.Resolve` 只有測試在用，正式程式碼另寫一份退回邏輯（低） | 移除 `Resolve`，測試改測 `GetOverride` |
