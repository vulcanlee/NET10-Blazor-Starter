## 二、實機驗證時發現並修正的問題

- **問題**：「我的對話」的標題一長，左側欄就被撐寬，右側對話區被擠得很窄。
- **原因**：側欄雖然設了 `flex: 0 0 240px`，但 flex 項目預設 `min-width: auto`，不換行的長標題會把它撐到最小內容寬度。
- **修正**：`AgentPlaygroundView.razor.css` 與 `AdminAssistantView.razor.css` 的 `.agent-playground-sidebar` 補上 `min-width: 0`，側欄固定 240px，標題以「…」截斷。Agent 測試台有同樣的問題，一併修正。

## 三、驗證過程中的資料異動（照實記載）
