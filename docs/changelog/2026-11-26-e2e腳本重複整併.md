# e2e 腳本重複整併（不升版，0.10.45）

- 日期：2026/11/26
- 版本：不升版（只改 `scripts/e2e` 的實機驗證腳本，不隨網站發佈）
- 起因：使用者 2026/11/26 要求檢查並整併重複程式碼、移除沒有使用的程式碼，分四批進行，本批是第四批（e2e 腳本）。原則是**行為不變，只搬程式**。
- 測試報告：[重複程式碼與死碼清理](../migration/測試報告/重複程式碼與死碼清理.md) D 章（改了什麼、如何證明沒有影響）。

## 搬到共用模組的函式

| 函式 | 放在 | 原本在 |
|---|---|---|
| `check`（情境判定） | `common.mjs` | m06-ai、m06-ops、m07-ops、m08-agents、m09-auth |
| `utcNow` | `common.mjs` | m06-ai、m06-ops、m07-ops、m09-auth |
| `createStep(recorder, { failurePage })`（情境步驟） | `common.mjs` | 上面 5 支的 `step`；有傳 `failurePage` 時照 m06-ai 原本的做法，失敗當下截圖並標出擋住點擊的元素 |
| `download` | `common.mjs` | m06-ai、m06-ops、m07-ops |
| `audits`、`auditCount` | `common.mjs` | m06-ops、m07-ops；m01-tokens、m06-ai |
| `fillLogin` | `common.mjs` | m09-auth、m09-views |
| `settle(page, wait = 800)` | `common.mjs` | 7 支畫面腳本（m07～m09 傳 1200，與原本相同） |
| `waitForRows(page, tableClass, { timeout })` | `common.mjs` | m03／m04／m05-views（m05 傳 60000、m04 傳表格 class，與原本相同） |
| `closeModal`（按關閉鈕）、`toolbar`（標籤含有即可） | `common.mjs` | m05-views、m06-views |
| `allLogText`、`waitForValue(check, timeout, interval)` | `common.mjs` | browser-reports、client-diagnostics；system-reports 以一行包裝保留原本的 3 分鐘、每秒一次 |
| `confirmSave` | `crud-ui.mjs` | m04-projects、m05-admin |

行為不同的同名函式刻意各自保留：m03-views 以 Esc 關窗的 `closeModal` 與沒有 `.first()` 的 `toolbar`、m06-ai 先避開提示框的 `closeModal`、m08-agents 逾時丟例外的 `waitFor`、m02-shell 以 `dotnet.*.js` 判斷的 `isWasmPage`、`crud-ui.mjs` 先比完全相符的 `clickToolbar`（與 `toolbar` 不同）、`explore-common.mjs` 本地時間的 `nowText`（與 `utcNow` 不同），以及 `pad`、`search`、`field`、`raw` 等內容不同的小函式。改動前就沒用到的 4 個 import（m04-projects 的 `confirmIfShown`、m06-ai 的 `apiAsPageUser` 與 `confirm`、m09-auth 的 `watchErrors`）不在本批範圍，未動。
