# .NET 11 全面實機探索（0.10.16）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.10.16
- 首次實作版本：0.10.16
- 最後核對日期：2026/11/14

## 目的

升級到 .NET 11 之後，使用者要求用瀏覽器實際連到每個畫面，模擬新增、修改、刪除等各種操作，盡可能探索每一步；除了找錯誤，也看效能與其他問題。
這一版先重跑全部既有的實機腳本，再新增六支探索腳本，涵蓋既有腳本沒有碰到的部分（每一個 API 端點、每個清單的每個操作、錯誤輸入、大量資料、慢速網路、離線、手機尺寸、語系與時區、維運與帳號流程）。
找到的問題都先寫測試重現再修；每一個都另外在升級前的 .NET 10 版本（0.10.13）重現過，確認是升級前就有、不是升級造成的。
測試結果見 [測試報告](../migration/測試報告/NET11全面實機探索.md)。

## 修正

### 1. 使用者換頁時中斷的請求被記成系統錯誤

- 使用者在查詢還沒回來時就換頁或關分頁，伺服器讀寫請求得到 `IOException: The client reset the request stream.` 或取消（例如系統健康頁讀警告日誌），`ApiExceptionFilterAttribute` 一律記成 Error、回 500，系統例外紀錄頁多出一筆「錯誤」。WASM 遷移以來（2026/11/10 起）的實機資料庫裡常見，.NET 10 一樣會發生。
- 改成：請求已被用戶端中止（`RequestAborted`）、且例外是 IO 例外或取消時，只記 Information、回 499（用戶端已經收不到）。其他例外照常記成 Error。

### 2. 關閉已被刪除的公告，系統例外紀錄多一筆

- 管理員刪除公告時，使用者畫面上的橫幅還在，按「關閉」寫入關閉紀錄撞外鍵。服務本來就接住這個例外，但 EF Core 在丟出之前已經把失敗記成 Error。
- 改成先確認公告還在，不在就不寫。

### 3. 可搜尋的下拉打字後一片空白

- 專案的分類與團隊（表單與工具列過濾）、使用者的額外角色與團隊、角色的預設團隊、分類的適用團隊、團隊的上層團隊九個下拉都開了搜尋，但選項文字只寫在子內容、沒有 `Label`，AntDesign 以 `Label` 比對，打任何字都比不到——搜尋形同不能用。
- 九處與 CRUD 產生器樣板都補上 `Label`；新增守門測試 `SearchableSelectConventionTests`。

### 4. 按「匯出 Excel」後提示框停在畫面上

- 0.10.12 讓工具列按鈕按下時收起提示框；但處理期間滑鼠還停在按鈕上，提示框又被打開，下載完之後滑鼠離開的事件沒有觸發，提示框一直停著（移開滑鼠也不收）。
- `ToolbarIconButton`、`CrudActionButton` 處理完成後再收一次。

## 評估後不採用

- **Runtime Async**（.NET 11）：在 API 主機開啟（`<Features>$(Features);runtime-async=on</Features>`，確認編譯後非同步狀態機由 435 個降到 18 個）後以發佈版量測，關、開、關交替各五次取中位數：API 與換頁沒有變快、存檔與匯出反而略慢（多在量測雜訊內）。依使用者「明顯變快且全部測試通過才採用」的決定維持關閉。

## 測試與實機腳本

- 新增測試：`ApiClientAbortTests`（5）、`Client/SearchableSelectConventionTests`、`NotificationTests` 與 `TooltipDismissTests` 各補情境；測試 3,209 → 3,218，品質關卡 7 步通過，`Test-CrudGenerator.ps1` 通過。
- 新增實機腳本 `scripts/e2e/explore-perm.mjs`、`explore-lists.mjs`、`explore-input.mjs`、`explore-edge.mjs`、`explore-ops.mjs`、`explore-auth.mjs` 與共用的 `explore-common.mjs`。
- 偶發失敗的單元測試：`ClientSessionTests` 的假 HTTP 處理器在背景重試與測試執行緒同時讀寫集合，全套測試負載高時偶爾失敗；改成加鎖。
- 實機共用工具修正：`crud-ui.mjs` 的 `clickToolbar` 依標籤完全相符比對（以前「搜尋」會先比到「清空搜尋」）；`confirmIfShown` 等「按下的那一個」確認窗關掉（接著跳出的下一個確認窗不會讓它一直等）。

## 升版注意

- 版本號 0.10.15 → 0.10.16。沒有資料庫異動、沒有設定異動。
- 呼叫 Web API 的外部程式：用戶端自己中斷的請求，伺服器的請求日誌記 499（以前是 500），用戶端本來就收不到回應。
- 衍生專案自己加的可搜尋下拉：選項要有 `Label`（`SearchableSelectConventionTests` 會提醒）。
