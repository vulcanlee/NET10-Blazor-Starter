# 錯誤頁失敗與空白 Host 修正（0.9.115）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.115
- 首次實作版本：0.9.115
- 最後核對日期：2026/10/05

## 起因

正式站（IIS 直接對外、沒有代理）的日誌出現同一個請求（追蹤碼 `H5YNJQSH`）連記 5 筆 ERROR，網站本身運作正常：

1. `UseHttpRequestLogging`：`GET /` 失敗，`UriFormatException: Invalid URI: The hostname could not be parsed`。
2. `UseHttpRequestLogging`：重跑的 `GET /Error` 失敗，`'RemoteNavigationManager' already initialized`。
3. 框架 `ExceptionHandlerMiddleware`：執行錯誤處理頁時又拋例外。
4. 框架 `ExceptionHandlerMiddleware`：原始例外再記一次。
5. `IISHttpServer`：沒有人接住，回 500。

每筆的堆疊印兩次，是 `nlog.config` layout `${exception:format=toString,StackTrace}` 的格式（ToString 已含堆疊），本次不改。

## 根因

- **觸發點：Host 空白。** Blazor SSR 以 `{Scheme}://{Host}{PathBase}/` 組 BaseUri。HTTP/1.0 可以不帶 Host 標頭（掃描器、直接打 IP 的機器人常見），組出 `https:///` 而拋例外。`AllowedHosts: "*"` 不過濾；就算改成指定網域，HostFiltering 預設 `AllowEmptyHosts = true`，空白 Host 照樣放行。一般瀏覽器一定帶 Host，所以使用者不受影響。
- **真正的 bug：錯誤頁本身失敗。** `Program.cs` 的 `app.UseExceptionHandler("/Error")` 自 Init 起就少了 `createScopeForErrors: true`（.NET 8 起 Blazor Web App 範本的預設寫法）。重跑 `/Error` 沿用原請求的 DI scope，NavigationManager 已經初始化，錯誤頁拋 "already initialized"。影響不限這次：**Production 任何 Blazor 頁面在 SSR 階段拋例外，使用者都只拿到空白 500，看不到錯誤頁與追蹤碼。**

## 異動

| 位置 | 改版後 |
|---|---|
| `Program.cs` | `app.UseExceptionHandler("/Error", createScopeForErrors: true)`，重跑錯誤頁時建立新的 DI scope |
| `ApplicationBuilderExtensions.UseRejectInvalidHost`（新增） | 以 `Uri.TryCreate($"{Scheme}://{Host}/")` 判斷，組不成網址就回 400，不進 Blazor；判斷方式與 Blazor 實際失敗的那一步一致 |
| `Program.cs` 管線順序 | `UseRejectInvalidHost()` 排在 `UseHttpRequestLogging` 之後（被擋的請求記一筆 Information `HTTP GET / responded 400`）、`UseStatusCodePagesWithReExecute` 之前（400 不會被重跑成 `/not-found`） |

同樣的請求現在只留一筆 Information，不再有 ERROR 與系統例外紀錄。

## 測試

`ErrorPageIntegrationTests.cs`（新增）：

- `ErrorPageRenderTests`：以 `ApiTestApplicationFactoryWithThrowingPage` 把 `PasswordResetService` 換成一解析就拋例外，`GET /Auths/ForgotPassword` 預期 500 且顯示「系統發生未預期的錯誤」與錯誤追蹤碼。修正前重現了正式站的 "already initialized"。
- `InvalidHostRequestTests`：Host 為空字串與 `exa mple.com` 時 `GET /` 預期 400，且沒有新增系統例外紀錄。修正前重現了正式站的 `UriFormatException`。

`SystemVersion` 由 `0.9.114` 遞增為 `0.9.115`。
