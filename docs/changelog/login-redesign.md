## 粉梅暖雪設計

`/Auths/Login` 採用選定的第 3–4 張設計稿：奶白粉梅冬景、層疊積雪、半透明粉色果凍面板與莓粉按鈕。桌面左側展示品牌、右側登入；手機改為精簡品牌與表單上下排列。背景為圖片素材，帳號、密碼、驗證碼、勾選框及按鈕都是可操作的 HTML 元件。

沿用 `SystemName`、`SystemDescription` 與既有品牌圖示；Cookie、記住我、驗證碼、ReturnUrl、Google 登入條件與伺服器表單送出流程均維持原有行為。

## 響應式與可讀性

- 1024px 起雙欄，內容最大 1200px，登入面板寬 460–520px。
- 768–1023px 單欄置中，最大 520px；767px 以下切換手機背景、隱藏長篇品牌說明。
- 最小支援 320px；359px 以下驗證碼改為上下排列。
- 輸入文字為 16px，欄位高度至少 52px，登入按鈕至少 56px，勾選標籤點擊區至少 44px。
- 沿用外層版面的垂直捲動；不固定表單高度，錯誤及 Google 登入可自然增加頁面長度。
- 色彩變數定義於 `.login-container`，避免隔離樣式的 `:root` 無法匹配文件根節點。無毛玻璃支援時使用較不透明淡粉底色。

## 動畫與無障礙

- 兩層透明雪花材質，以 18／28 秒循環向下移動與微幅橫移，手機只保留一層。
- 品牌與面板於 450／600ms 淡入並上移 8px；表單不持續漂浮。
- 聚焦欄位於 200ms 柔光增亮、上移 1px，標籤及驗證碼顯示區同步變色；逐字輸入不觸發彈跳。
- 勾選框 180ms 小幅回彈；按鈕懸停上移 2px，按下縮至 98%，220ms 回復。
- 錯誤訊息以 `role="alert"` 呈現，200ms 淡入；沒有錯誤時不顯示空白提示區。
- 雪花置於內容後方，`aria-hidden` 且不攔截滑鼠。持續動畫僅使用 `transform`，不持續變動模糊或陰影。
- `prefers-reduced-motion: reduce` 停止飄雪、進場與彈性動畫，保留清楚焦點及即時色彩回饋。懸停效果限支援滑鼠的裝置。

## 圖像素材

三張素材均使用內建 imagegen 生成，儲存於 `src/MyProject/MyProject.Web/wwwroot/images/`：

| 素材 | 用途與生成要求 |
|---|---|
| `login-winter-desktop.png` | 以選定桌面稿為參考，移除所有文字、Logo 與表單，保留左上粉梅、暖粉天空、冬日湖景與三至四層積雪，中段供真實 UI 使用。 |
| `login-winter-mobile.png` | 以選定手機稿為參考，移除所有 UI，保留相同配色，梅枝靠上與兩側，中央低對比留白，底部層疊積雪。 |
| `login-snow.png` | 稀疏柔白雪粒、大小略有差異、真正透明背景，可重複鋪排；已驗證包含透明及半透明 alpha。 |

透過 `Assets` 參照靜態素材，桌面與手機由 `picture/source` 切換，避免手機同時下載兩個背景。品牌圖示繼續沿用 `brand-logo.png`。

## 維護與驗證

改動集中於 `Login.razor`、`Login.razor.css` 及三張素材，沒有修改 `Login.razor.cs` 的驗證流程。版本由 0.9.22 更新為 0.9.23；未自動建立 commit。

驗證包含建置、既有登入測試、格式唯讀檢查、文件 BOM 檢查、五種寬度的瀏覽器版型，以及隔離資料庫下的伺服器表單回歸。實際畫面與測試限制詳見專案根目錄 `design-qa.md`。
