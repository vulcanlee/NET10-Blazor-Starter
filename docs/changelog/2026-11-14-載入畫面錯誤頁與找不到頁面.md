# 首次載入畫面、錯誤頁與找不到頁面（0.10.13）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.10.13
- 首次實作版本：0.10.13
- 最後核對日期：2026/11/14

## 目的

使用者以 Visual Studio 第一次開啟 WASM 專案時回報四件事：主控台出現兩個錯誤、第一次開啟要等很久而畫面一片空白、找不到頁面是英文、錯誤頁沒有樣式。這一版逐一處理。
測試結果見 [測試報告](../migration/測試報告/介面改善-載入與錯誤頁.md)。

## 變更內容

### 1. 首次載入不再整片空白

- `MyProject.Web.Client/wwwroot/index.html` 的 `#app` 放靜態的載入卡片：系統名稱、進度條與百分比、「正在載入，請稍候…」、「第一次開啟需要下載程式，之後會更快」。進度讀 Blazor 下載時設的 CSS 變數 `--blazor-load-percentage`／`--blazor-load-percentage-text`，不需要行內腳本（CSP 只允許 import map）。樣式在 `wwwroot/app.css`。
- 新元件 `Commons/ClientLoadingScreen.razor`：外框 `ClientMainLayout` 在登入檢查與讀取外框資料期間、登入相關頁（登入、忘記密碼、重設密碼、兩步驟驗證）讀取設定期間、登出期間顯示同一張卡片，接續下載期間的那一張。閘門不變：卡片只有固定的名稱與說明文字。
- 啟動失敗（第一次開啟就離線、部署後手改檔案導致完整性驗證失敗、瀏覽器不支援）時卡片不會被取代：30 秒後以純 CSS 浮現「若一直停在這個畫面，請重新整理；仍然無法開啟請聯絡系統管理員。」，不會讓人以為還在載入。
- 實機（限速約 4 Mbps、無快取）：從第一個畫面到登入表單出現，每 150 毫秒取樣都有畫面，進度 0%→100% 連續前進；已登入重新整理時下載卡片接著「正在確認登入狀態…」卡片，中間沒有空白。

### 2. 系統錯誤頁 `/Error`

- 改成整頁置中卡片（深色漸層與玻璃卡片，手法同帳號待審核頁），新元件 `Commons/StatusCard.razor`。
- 錯誤追蹤碼附「複製」；按鈕「回首頁」「回上一頁」（沒有上一頁時回首頁）。原本計畫的「重新整理」在這一頁只會再顯示錯誤頁（出錯的網址已換成 `/Error`），改成「回上一頁」。

### 3. 找不到頁面

- 「Not Found／Sorry, the content you are looking for does not exist.」（Blazor 樣板原文）改成繁體中文卡片「找不到這個頁面」＋說明＋「回首頁」，顯示在外框內；頁首標題由「系統首頁」改成「找不到頁面」。
- Blazor 未處理例外時畫面底部的提示列（`#blazor-error-ui`）與預設錯誤邊界的文字也改成繁體中文。

### 4. 開發環境的 CSP

- 主控台的兩個錯誤是 Visual Studio「瀏覽器連結」（Browser Link）連到 `http://localhost:<埠>/…/browserLinkSignalR/negotiate`，被前端 CSP 的 `connect-src 'self'` 擋下。
- 只有 Development 時，同站台主機在 `connect-src` 另外允許 `http(s)://localhost:*`、`ws(s)://localhost:*`（`FrontendContentSecurityPolicy.LocalDevToolSources`），瀏覽器連結與熱重載不再被擋。正式環境與靜態站 `web.config` 不變。

### 5. 測試與實機腳本

- 新增 `Components/LoadingAndStatusPageTests`、`FrontendDevelopmentCspTests`；`PageAuthorizationTests`（`#app` 只有載入卡片）、`SameSiteHostTests`（測試環境的 CSP 不含 localhost）、`ClientSessionTests`（頁首標題、`WaitUntilReachable` 的上限放寬以免負載高時偶發失敗）調整。
- 新增實機腳本 `scripts/e2e/ux-loading-pages.mjs`（L1～L6，同站台與雙站台都可跑）與 `scripts/e2e/perf.mjs`（效能量測，升級 .NET 11 前後比較用）；`Start-E2EHost.ps1` 新增 `-Published`（以 Release 發佈後執行）。
- `m09-views.mjs`、`m12-pwa.mjs` 改認新的畫面。
- 測試 3,161 → 3,184，品質關卡 7 步通過；獨立審查 1 項中、5 項低與文件遺漏全部處理（見測試報告 A.5）。

## 升版注意

- 版本號 0.10.12 → 0.10.13。沒有資料庫異動、沒有設定異動。
- ⚠️ 改 `SystemName` 時，除了 `manifest.webmanifest`，還要改 `index.html` 的載入卡片與 `Commons/ClientLoadingScreen.razor` 的 `FixedSystemName`（`LoadingAndStatusPageTests` 會提醒）。
- 衍生專案若在 `index.html` 的 `#app` 加了自己的內容：根元件掛上後會被取代，這是預期行為。
