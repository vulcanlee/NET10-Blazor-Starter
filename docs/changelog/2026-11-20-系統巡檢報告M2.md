# 系統巡檢報告 M2：報告可下載 PDF，通知信附上 PDF（0.10.40）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.10.40
- 首次實作版本：0.10.40
- 最後核對日期：2026/11/20

## 目的

使用者 2026/11/20 要求系統巡檢報告以 **PDF 分析報告**寄給管理員（見 [M1](2026-11-20-系統巡檢報告M1.md)）。M1 交付了日報與報告頁，信件只有程式摘要與連結；M2 讓報告可以下載成 PDF，寄給管理員的信也附上 PDF，管理員不登入系統也能看完整報告、轉寄主管或歸檔。

需求、決定與規則目錄見 [系統巡檢報告 PRD](../prd/系統巡檢報告-prd.md) 5.4。

## 決定

- PDF 由存好的報告內容 JSON **隨需產生**，不另存 PDF 檔、不加欄位、沒有 migration；舊版巡檢報告沒有 PDF。
- PDF 去除敏感內容（不放路徑、設定值、例外內文、帳號，與報告頁相同），不加密碼；PDF 內含 AI 說明，**AI 說明仍不進通知與信件內文**。
- 附件做成寄信層的通用能力（`EmailMessage.Attachments`），和內文一起加密存進寄信佇列、寄出後一起清除；一封信附件總計 ≤ 8 MB，超過或產生失敗時不附、改請收件人由連結下載，通知照常送出。
- 下載 PDF 時報告離開系統，所以寫稽核；看報告本身仍不寫。

## 變更內容

### PDF 報告（`SystemReportPdfBuilder`）

- 新增 `MyProject.Web/SystemReports/SystemReportPdfBuilder`，版面順序與報告視窗相同：
  - 標題（例「系統巡檢日報 2026/11/19」），系統、涵蓋區間、產生時間、整體燈號，並註明燈號與數字由程式規則判定、AI 說明僅供參考。
  - 全面摘要：燈號色塊與一句話結論、已發生問題（附處理方式）、即將發生（附期限）、注意即可（最多 10 項）、需要準備擴充容量、下期預測。
  - AI 說明（沒有時寫出原因）。
  - 每一項發現：每項一個表格，現況／不處理會怎樣／怎麼處理／處理完會怎樣／期限；處理頁面寫中文頁面名稱，不放網址。
  - 磁碟容量、資料目錄、統計，最後是附錄「燈號的意思與量測限制」。
- 燈號以文字加淺色底色呈現，不用表情符號。字型用 `AiMarkdownPdfRenderer` 內嵌的 Noto Sans TC，中文可在字元間換行。
- 檔名只用英數字：`system-report-{頻率小寫}-{區間起日 yyyyMMdd}.pdf`（例 `system-report-daily-20261119.pdf`）。

### 下載 PDF

- 報告內容視窗內右上方新增圖示按鈕「下載 PDF」：下載中停用；成功提示「PDF 已產生並開始下載。」，失敗「PDF 下載失敗：…」。
- API `POST api/v1/system-reports/{id}/pdf`（`[AdminOnly]`，回 `application/pdf`）：找不到報告或內容檔 404；內嵌字型缺失 500「缺少內建中文字型，請確認建置產物完整。」。
- 稽核 `SystemReport.Download`：targetType `SystemReport`、targetId 報告編號（`N` 格式）、detail `format=pdf; frequency=Daily`。

### 寄信層：附件（通用）

- `EmailMessage` 新增選擇性的 `Attachments`（`EmailAttachment(FileName, ContentType, Content)`），上限 `EmailAttachment.MaxTotalBytes`＝8 MB（由呼叫端檢查）。
- `EmailBodyProtector` 把附件包進同一份 Data Protection 加密的內文 JSON（`{Html, Text, Attachments?}`），寄出或放棄後與內文一起清除；不新增欄位、沒有 migration；重試寄出相同的位元組；升級前排入、沒有附件的舊格式照樣寄出。
- `MimeMessageFactory` 有附件時外層是 multipart/mixed，沒有附件時維持 multipart/alternative。日誌仍只記 `Kind`，不記附件檔名與大小。
- 新信件種類 `EmailKinds.SystemReport`，「寄信紀錄」頁顯示「系統巡檢報告」。

### 站內通知：信件選項

- `NotificationRequest` 新增選擇性的 `Email`（`NotificationEmailOptions`：`Kind`、`Attachments`、`ExtraText`）；`ExtraText` 只加在信件內文最後，不進鈴鐺通知。`INotificationMailer.Send` 多一個選擇性參數接收它。

### 系統巡檢報告的信

- 寄給全體管理員的信（日報橙燈以上、「立即產生」勾選「產生後寄給所有管理員」；週報與月報在 M3）：內文是原本的程式摘要＋報告連結按鈕＋「完整報告請見附件 PDF（system-report-daily-20261119.pdf）。」，並附上 PDF。
- PDF 產生失敗：不附，內文寫「PDF 產生失敗沒有附上，請由連結到系統查看與下載報告。」（記 Error）。
- PDF 超過 8 MB：不附，內文寫「PDF 太大沒有附上，請由連結到系統查看與下載報告。」（記 Warning）。
- 「立即產生」沒勾寄送時只以站內通知告訴產生者，照舊不寄信。

## 已知限制

- PDF 每次下載與寄信都重新產生；報告內容檔不見時無法產生 PDF（可在保留天數內重新產生那一天的日報）。
- 附件上限 8 MB，超過時信中只有連結。
- 週報與月報（一律寄出、附 PDF）、備份可還原驗證、AI 費用、每季帳號與權限清查（M3），系統管理助理依指定區間產生報告與 PDF（M4）尚未實作。
