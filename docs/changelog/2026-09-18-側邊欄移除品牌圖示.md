# 側邊欄移除左上品牌圖示（0.9.19）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.19
- 首次實作版本：0.9.19
- 最後核對日期：2026/09/18

## 起因

使用者指著側邊功能表**往右展開後**的左上角反映：品牌文字「企業管理平台」左側那顆
**深色圓角方塊**（Material 圖示 `dashboard_customize`）要移除。

那顆方塊看起來像按鈕（深色漸層底、`border-radius: 18px`、陰影），
實際上是 `<div>` 包一個 `MaterialIcon`，**沒有 `@onclick`、沒有 `href`、沒有 tooltip** ——
純裝飾。展開時它又緊貼在藍色漢堡鈕右邊，兩顆相鄰的圓角方塊只有一顆能按，
語意上是誤導。

## 變更內容

| 檔案 | 異動 |
|------|------|
| `src/MyProject/MyProject.Web/Components/Layout/NavMenu.razor` | 刪除 `.sidebar-brand` 內的 `<div class="sidebar-brand-icon">` 區塊（含其 `MaterialIcon`） |
| `src/MyProject/MyProject.Web/Components/Layout/NavMenu.razor.css` | 刪除 `.sidebar-brand-icon` 整條規則（該 class 全專案僅此一處使用，留著就是死 CSS） |
| `src/MyProject/MyProject.Web/appsettings.json` | `SystemVersion` 0.9.18 → 0.9.19 |

改完後 `.sidebar-brand` 只剩 `.sidebar-brand-text` 一個子元素，品牌文字往左靠
（原本被圖示的 `3rem` 寬度 ＋ `gap: 0.9rem` 推開）。

## 為什麼是「從標記刪掉」而不是「展開時才隱藏」

這顆圖示原本**永遠存在於 HTML**，沒有任何 `@if`；看不看得到全由 CSS 決定，
而兩種螢幕寬度走的是**不同機制**：

| 狀態 | 改前 | 改後 |
|------|------|------|
| 桌機（≥641px）展開 | 顯示深色方塊 | **消失**，左上只有漢堡鈕＋品牌文字 |
| 桌機（≥641px）收合 | 已被 `.top-row-collapsed .sidebar-brand { display: none; }` 整塊藏起 | 無變化 |
| 窄螢幕（<641px）收合 | `top-row-collapsed` 的規則不適用，只有 `.sidebar-brand-text` 塌掉（`opacity: 0; width: 0`），**深色方塊仍會露出來** | **消失** |

也就是說「只在展開時隱藏」反而會留下窄螢幕收合時那顆孤零零的深色方塊。
既然它純裝飾、沒有任何行為，直接從標記移除最單純，也不必新增條件渲染。

## 刻意不動的東西

- **`.sidebar-brand` 外層 `<div>` 保留**：`.sidebar-brand-collapsed .sidebar-brand-text`
  與 `.top-row-collapsed .sidebar-brand` 兩個收合選擇器都掛在它身上，拆掉要重接線。
  其 `gap: 0.9rem` 在只剩一個子元素後變成無作用宣告，但無害，不順手改。
- **啟動頁／登入後首頁 Hero 的 `wwwroot/images/brand-logo.png` 未動** —— 那是品牌圖片，
  與本次移除的 Material 圖示是不同東西。
- 漢堡鈕（`.sidebar-hamburger`／`ToggleSidebar`）與選單本體、權限、路由皆未動。
- 歷史 changelog 與指南裡提到 `dashboard_customize` 的敘述（如
  [0.9.10 首頁圖示](2026-09-16-側邊欄首頁圖示改為home.md)、
  [0.9.16 死 CSS 清理](2026-09-16-匯出BOM修正與圖示死CSS清理.md)）維持原狀，那是當時的紀錄。
