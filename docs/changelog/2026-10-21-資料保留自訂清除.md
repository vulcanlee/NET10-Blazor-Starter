# 資料保留與清理：自訂清除與操作欄固定右側（0.9.134）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.134
- 首次實作版本：0.9.134
- 最後核對日期：2026/10/21

## 起因

使用者打開「資料保留與清理」頁，以為沒有手動刪除的地方：「操作」欄被擠到畫面外，要捲到最右邊才看得到；而且「立即清理」只刪超過保留期限的資料，資料都還沒過期時按了也是 0 筆。使用者要的是在這一頁自己決定刪多少。

## 決定（2026/10/21，與使用者逐項確認）

| 項目 | 決定 |
|---|---|
| 刪除方式 | 「自訂清除」由使用者二選一：只留最近 N 天，或刪除某一天之前（不含當天）；先預覽會刪幾筆，確認後才刪；不改系統參數 |
| 適用資料 | 系統例外紀錄、Token 用量、AI 對話紀錄、稽核紀錄、站內通知、排程執行紀錄、已刪除的五種資料 |
| 已刪除資料 | 只清按下的那一種；support、預設角色、使用中的角色、有下屬的部門照舊留下 |
| 操作欄 | 固定在表格最右側 |
| 我的判斷（已告知） | 系統備份、日誌檔、公告不提供；在頁面上同步執行（同各頁「批次清除」）；站內通知只依建立時間；N 為 1～3650，日期不可晚於今天 |

## 注意

- 「自訂清除」會在頁面上等待刪除完成，資料量很大時要等一下（Token 用量分批刪，不會長時間鎖住資料庫）。
- 已刪除資料途中有一筆失敗時停止，前面刪掉的仍寫稽核，通知會說明。
