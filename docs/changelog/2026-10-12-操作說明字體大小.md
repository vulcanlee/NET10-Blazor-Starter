# 操作說明字體大小（0.9.121）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.121
- 首次實作版本：0.9.121
- 最後核對日期：2026/10/12

## 起因

操作說明窗的字體固定（內文 14px），有人看起來吃力。使用者希望窗內提供「大／中／小」按鈕，依點選自動調整字體。

決定（2026/10/12）：按鈕放在標題列右側；「中」＝原本大小（小約 13px、大約 17px），預設「中」；選擇記在這個瀏覽器；內文與左側目錄一起縮放。

## 異動

| 位置 | 改版後 |
|---|---|
| `Components/Commons/PageHelpDialog.razor` | Modal 改用 `TitleTemplate`：標題＋「字體 小／中／大」按鈕組（`role="group"`、`aria-pressed`）；內容外層加 `page-help-font-*` class |
| `Components/Commons/PageHelpDialog.razor.cs` | `PageHelpFontSize`／`PageHelpFontSizes`（選項、CSS class、存值對照，讀不到或無效一律「中」）；第一次開窗讀 localStorage `app.helpFontSize`，點按鈕即套用並寫回；localStorage 拋例外時照常開窗 |
| `Components/Commons/PageHelpDialog.razor.css` | `.page-help-layout` 以 `--page-help-scale`（小 13/14、中 1、大 17/14）縮放；h1／h2／h3 與目錄的 rem 字級改為 `calc(原值 * var(--page-help-scale))`，「中」時與之前逐一相同；按鈕組樣式只用 theme token |
| 文件 | 首頁與導覽 PRD（操作說明一節）、速查表 §6.14（新增字級樣式要乘倍率） |

## 測試與驗證

- `PageHelpFontSizesTests`（新增）：三種大小的存值與 CSS class 對照、沒存過／大小寫不同／無效值回「中」、選項順序。
- 實機（暫存資料目錄＋全新資料庫，Playwright 驅動 Edge），量測 computed font-size：

| 選擇 | 內文 p／li／td／code | h1 | h2 | h3 | 左側目錄 |
|---|---|---|---|---|---|
| 改版前 | 14px | 21.6px | 18.4px | 16px | 14.4px |
| 小 | 13px | 20.06px | 17.09px | 14.86px | 13.37px |
| 中 | 14px | 21.6px | 18.4px | 16px | 14.4px |
| 大 | 17px | 26.23px | 22.34px | 19.43px | 17.49px |

- 目前的選擇以 `aria-pressed` 與重點色標示；換頁後重開仍是同一個大小；整頁重新整理後從 localStorage 讀回；全新瀏覽器為「中」；存值被改成無效值時回「中」。窗標題字級不變（16px）。

`SystemVersion` 由 `0.9.120` 遞增為 `0.9.121`。
