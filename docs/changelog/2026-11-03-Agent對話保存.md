## 目的

MAF 四階段計畫第三階段的 **B：對話保存**。0.9.142 的 Agent 測試台對話只在記憶體，離開或重新整理就消失；
交接知識助理這類功能需要「昨天問到一半、今天接著問」。這一版把 Agent 對話存下來（中繼資料進 SQLite、內容進檔案系統），
可以接續，停在核准的對話回來時重新跳核准窗；保存期限、清理、備份與資料保留頁比照 AI 對話紀錄接上。
設計見 [MAF AI 呼叫架構 §6.7](../architecture/MAF-AI呼叫架構.md)。下一步是第四階段（多 Agent 工作流程）。

## 一、存什麼、存在哪裡

- 新資料表 `AiAgentConversation`（migration `AddAiAgentConversation`）：`ConversationId`（唯一，與 `AiCallLog.ConversationId` 相同）、`UserId`、`Account`、
  `AgentName`、`Title`（各 ≤100 字）、`CreatedAt`、`UpdatedAt`（最後一次對話，本地時間；清單排序與自動過期都依它）、`HasPendingApproval`、`ContentFile`。
  索引：`ConversationId` 唯一、(`UserId`, `AgentName`, `UpdatedAt`)、`UpdatedAt`。
- 內容檔 `{SystemSettings:ExternalFileSystem:AiAgentConversationPath}/{yyyyMM 建立時間}/{ConversationId:N}.json`，每次儲存整份覆寫。
  結構 `AiAgentConversationContent`（`SchemaVersion` 1）：`Session`（MAF `SerializeSessionAsync`，讓 AI 記得前文）、`Transcript`（畫面紀錄：User／Assistant／Tool／Notice／Error）、
  `PendingApprovals`（等使用者決定的核准請求，或工具已不存在而自動拒絕的回覆）。讀到不認得的 `SchemaVersion` 一律當作讀不到。
- `AiAgentConversationFileStore`（Business/Services/Other）：內容檔的唯一入口，絕不拋出，比照 `AuditContentFileStore` 擋下跑出根目錄的路徑。
  ⚠️ 月份目錄是建立時間、過期看最後一次對話，所以清理只逐檔刪、最後收掉空的月份目錄，**不**像 AI 對話紀錄那樣整個刪舊月份。

## 二、存檔與接續

- `AiAgentChat` 自己維護 `Transcript`（畫面直接呈現），每次執行結束都存一次：成功、失敗、停止產生、停下來等核准，以及呼叫端中途不再讀取（例如離開頁面）；
  已收到的文字收進紀錄並標示不完整。第一則訊息之前不存（只按「新對話」不會多出空白對話）。存檔失敗只記警告，不影響對話。
- 自動標題：第一則訊息（空白與換行收成一格）的前 40 字＋「…」，只在第一次儲存時寫入。
- `IAiAgentRunner.ResumeAsync(定義, ConversationId)`：讀回本人的對話、重新建立 agent（模型與提示詞用**目前**的設定）、還原 session、畫面紀錄與待核准；
  沿用同一個 `ConversationId`，AI 對話紀錄前後串成同一段。找不到、不是本人的、不是這個 Agent 的、內容檔不見或 session 讀不回來時回 null。
- 停在核准的對話接續時重新跳核准窗；權限不在還原時檢查，使用者核准後由工具外殼在真正執行前以現在的權限再檢查。待核准的工具已不在 Agent 上時自動拒絕、隨下一則訊息送出。

## 三、只限本人

- `AiAgentConversationService`（Business/Services/DataAccess）實作窄介面 `IAiAgentConversationStore`（`SaveAsync`、`LoadMineAsync`，執行器只依賴它）。
  讀、清單（`ListMineAsync`，新到舊、最多 100 段）、改名（`RenameAsync`，1～100 字）、刪除（`DeleteAsync`）一律以目前使用者過濾，別人的對話當作找不到。
- 規劃時寫「本人＋管理員可見」，實作改為**只限本人**；管理員要追查仍可在「AI 對話紀錄」以同一個 `ConversationId` 看到每一次模型呼叫。
- 稽核新增 `AiAgentConversation.Delete`（detail 只有 `agent=…`）、`AiAgentConversation.Purge`（資料保留頁自訂清除）、`AiAgentConversation.AutoPurge`
  （detail `rows=…; days=…; trigger=…`），不記標題與內容；改標題不寫稽核（標題只給本人看）。稽核頁標籤為洋紅色。`AuditActions` 共 140 個常數。

## 四、Agent 測試台畫面

| 項目 | 0.9.142 | 0.9.143 |
|---|---|---|
| 對話 | 只在記憶體 | 左側「我的對話」：標題、最後對話時間（yyyy/MM/dd HH:mm）、「待核准」標籤；點一下接續 |
| 每段對話的操作 | — | 「重新命名」（小視窗，1～100 字）、「刪除這段對話」（危險確認；AI 對話紀錄與 Token 用量不受影響）；回覆中停用 |
| 接不下去時 | — | 紅色提示「這段對話無法接續：內容可能已被清除，或格式已不相容。可以刪除它後開新對話。」 |
| 頁首說明 | 對話不保存 | 對話自動保存、只有本人看得到、最後一次對話超過 N 天自動刪除 |
| 使用模型 | 開新對話時決定 | 同左；接續舊對話時改用目前的模型 |

## 五、保存期限、清理、備份

- 新設定區段 `AiAgentConversationSettings { RetentionDays = 90 }`（`[Range(1, 3650)]`、`ValidateOnStart`，沒有「不清除」）。
- 新路徑 `SystemSettings:ExternalFileSystem:AiAgentConversationPath`（預設 `C:\temp\MyProject\AiAgentConversation`）：必填完整路徑、不可與 `BackupPath` 重疊、
  啟動時建立；🔴 不可放在 `DownloadPath` 底下。`Restore-Backup.ps1` 多 `-AiAgentConversationPath`；`New-CrudModule.ps1` 的隔離環境一併設定。
- 系統參數（共 47 個）：「資料保留」加「Agent 對話保留天數」（`AiAgentConversationSettings:RetentionDays`，下一次排程清理時；Agent 畫面上的天數說明立即），
  「備份」加「備份 Agent 對話」（`BackupSettings:IncludeAiAgentConversations`，預設關閉，下一次備份起）。
- 排程作業 `AiAgentConversationRetention`「Agent 對話清理」（`0 3 * * *`）：刪除最後一次對話早於「今天 0 點減 N 天」的對話與內容檔（全體使用者）。
- 備份開啟時多 `files/AiAgentConversation`（備份頁「內容」顯示「Agent 對話」）；不備份時還原後清單仍在、點開提示無法接續。
- 資料保留與清理頁多一列「Agent 對話」（AI 對話紀錄之後，共 15 列）：附註「全體使用者，連同內容檔；依最後一次對話時間」、單位「段」、
  保留規則「最後一次對話後保留 N 天」、立即清理、自訂清除（以日計）、前往 `/agent-playground`。
