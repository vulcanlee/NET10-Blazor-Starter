# 移除「設定 API 密碼」：Google 帳號只用於網頁登入（0.9.63）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.63
- 首次實作版本：0.9.63
- 最後核對日期：2026/09/24

## 為什麼

使用者選單的「設定 API 密碼」（`/Profile`）讓沒有本地密碼的 Google 帳號免驗舊密碼自設一組密碼，再拿去打 `/api/v1/auth/login` 換 JWT。
這組密碼其實寫進同一個 `MyUser.Password`，對一般帳號等同第二個「變更密碼」入口，頁面上「此密碼僅供 API 存取使用」的說明也與實際不符。
經決定移除此功能：**Google 帳號只用於網頁登入，不支援 API**；要呼叫 API 請使用本地帳號。

## 做了什麼

- 刪除 `Components/Pages/Profile.razor`（`/Profile`）。
- `MainLayout.razor` 使用者選單移除「設定 API 密碼」，剩「變更密碼、關於、登出」。
- 刪除只供該頁使用的 `MyUserService.HasLocalPasswordAsync`、`MyUserService.SetOwnApiPasswordAsync`。
- `PageAuthorizationTests` 的 `CheckWithoutGateAllowList` 拿掉 `Profile`。
- 原訂 0.9.63 的《寄信服務使用說明》再順延為 0.9.64。

## 影響

- **Google 帳號**：不能再自己設密碼，因此無法取得 JWT。「變更密碼」要驗目前密碼、「忘記密碼」對沒有本地密碼的帳號回 `NoLocalPassword`，兩者規則不變。
- **已經設過密碼的 Google 帳號**：那組雜湊仍留在 `MyUser.Password`，系統**不主動清除**，照樣能以帳號＋密碼登入網頁與 API。
- **一般本地帳號**：不受影響，繼續用「變更密碼」。
- **直接開 `/Profile`**：路由已不存在，顯示找不到頁面。
