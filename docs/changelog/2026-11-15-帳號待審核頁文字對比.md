# 帳號待審核頁文字對比（0.10.29）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.10.29
- 首次實作版本：0.10.29
- 最後核對日期：2026/11/15

## 目的

使用者 2026/11/15 回報：Google 登入後出現的「帳號待審核」頁（`/Auths/Pending`），標題「帳號已建立，等待審核」在深紅漸層上是深色字，幾乎看不到。希望參考系統錯誤頁（`/Error`）的配色。

原因：

- 帳號待審核頁有自己的一份卡片樣式（`Pending.razor.css`），`h1` 沒有設定顏色，被全站的標題預設色蓋成深色字。
- 系統錯誤頁用共用元件 `Commons/StatusCard.razor`，0.10.13 已經用 `color: inherit` 修過；兩頁是同一套設計、各寫一份樣式，修了一邊、漏了另一邊。

順便發現的對比問題（估算，一般文字的標準是 4.5:1）：

- 卡片內文是白色、84%／82% 不透明，約 4.3:1；背景漸層流到亮粉紅時更低。
- 「請在管理者啟用您的帳號後…」用粉紅色 `--app-accent-light`，約 3.5:1。這是使用者最需要看到的指示，卻是整張卡片最難讀的一行。

使用者的決定：

1. **帳號待審核頁改用共用的 `StatusCard`**，刪掉重複的樣式，以後改一次兩頁一起生效。
2. **內文與提示行一起調亮**：提示行改成近白色粗體，不再用粉紅色。

## 變更內容

- `Views/Auths/Pending.razor`：改用 `<StatusCard Icon="schedule" FullScreen="true">`（Material 的時鐘圖示，取代原本的 SVG 時鐘）；文字、按鈕「返回登入頁」都沒變。
- 刪除 `Views/Auths/Pending.razor.css`。
- `Commons/StatusCard.razor.css`：
  - 整頁版內文改成完全不透明的 `--app-on-accent`，加一層淡陰影 `0 1px 2px rgba(--app-shadow-rgb, 0.35)`。系統錯誤頁的內文也一起變清楚。
  - 新增 `status-card-hint`：粗體；整頁版用 `--app-on-accent`，外框版用 `--app-text`。
- e2e 腳本等待的選擇器 `.pending-card` → `.status-card`：`m09-views.mjs`、`smoke-routes.mjs`、`walkthrough.mjs`。
