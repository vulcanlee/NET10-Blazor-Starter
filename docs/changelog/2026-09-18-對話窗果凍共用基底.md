# 果凍改成共用基底，補齊被漏掉的五個對話窗（0.9.28）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.28
- 首次實作版本：0.9.28
- 最後核對日期：2026/09/18

## 為什麼改

使用者指出「關於」對話窗沒有果凍效果。查證屬實，而且不只它 —— **五個對話窗都還是白盒子**：

| 對話窗 | class | 0.9.27 的規則 |
|---|---|---|
| 關於 | `.about-modal` | 只有尺寸 |
| 變更密碼 | `.change-password-modal` | 只有尺寸 |
| 例外明細 | `.exception-log-modal` | 尺寸 ＋ 內容樣式 |
| Token 明細 | `.token-usage-modal` | 尺寸 ＋ 內容樣式 |
| AI 分析 | `.log-ai-modal` | 只有尺寸 |

**根因是結構，不是漏改。** 0.9.25 與 0.9.26 都用「加法」做 —— 只針對 `.form-modal` 與
`.ant-modal-confirm` 各寫一份果凍，沒被點名的窗自動落空，下一個新增的窗也會再落空一次。

## 改了什麼

### 果凍上提到共用基底

```
.ant-modal                      CSS 變數 --ov-*（色票、圓角、模糊度）
.ant-modal .ant-modal-content   果凍基底 —— 邊框、圓角、毛玻璃、內外亮邊、ov-arrive 380ms
.ant-modal .ant-modal-header / -footer / -title / -close
.ant-modal-footer .ant-btn      膠囊圓角 ＋ Q 彈回饋
.ant-modal .ant-input …         圓角 ＋ 聚焦柔光

  ├─ .form-modal         --ov-radius: 34px、--ov-blur: 26px、fm-arrive 620ms、95vh flex 版型
  ├─ .ant-modal-confirm  440px、:has(.ant-btn-dangerous) 轉紅調
  └─ 其餘                只寫尺寸
```

**所有對話窗（含未來新增的）自動吃到果凍**；各自的 class 只負責尺寸與捲動版型。
要調整單一窗的果凍強度，覆寫 `--ov-radius` / `--ov-blur` / `--ov-tint-glass` 即可。

`.form-modal` 與 `.ant-modal-confirm` 原本各自重寫的邊框、毛玻璃、標題列配色、
按鈕膠囊、輸入框聚焦柔光、`prefers-reduced-motion` 降級，全部上提，兩邊的重複也一併消掉。

### 沒有按鈕列的窗

「關於」用 `Footer="null"`，body 的下緣就是窗的下緣。基底以
`.ant-modal .ant-modal-body:last-child` 接住下圓角，否則會被切平。

### 唯讀明細窗的內容配色

`.exception-log-detail-list` 與 `.token-usage-detail-list` 原本是灰藍 slate
（`dt: #64748b`、`dd: #0f172a`、分隔線 `#f1f5f9`），在粉梅玻璃底上顯得突兀，
改用基底的 `--ov-muted` / `--ov-text` / `--ov-line`。

⚠️ **堆疊追蹤區（`.exception-log-stack`）刻意維持深色 `#0f172a`** ——
那是程式碼，深色等寬底最好讀。只把圓角調成 14px、補一圈淡邊，讓它讀起來就是「一塊程式碼」。
`.token-usage-raw-list dt` 的紅色等寬字同理不動。

## 守門

`FormModalConventionTests` 新增第七項：`OverlayStyles.razor` 必須存在
`.ant-modal .ant-modal-content` 基底規則與 `ov-arrive` keyframe。

這條測試擋的是「有人把基底拆掉、退回逐一加法」。真正防止漏窗的是**結構**，
測試只負責不讓結構被拆。

## 不在本次範圍

- **斷線重連提示**（`Components/Layout/ReconnectModal.razor`）：原生 `<dialog>`、
  自己一套 CSS 與動畫，不走 AntDesign，因此不受這次的基底影響。
- **遮罩**：維持 AntDesign 預設的黑色半透明，沒有改成暖粉調。
