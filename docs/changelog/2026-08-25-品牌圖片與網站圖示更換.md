# 更換品牌圖片與網站圖示，品牌名稱收斂為單一來源（0.4.25）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.4.42
- 首次實作版本：0.4.25
- 最後核對日期：2026/08/26

## 目的

移除腳手架殘留的 Blazor 預設品牌素材，並修正一個連帶的顯示缺陷：

1. Splash 畫面的「產品圖片」實際上直接引用 `wwwroot/favicon.png` —— 也就是 .NET 範本自帶的 Blazor 圖示。同一個檔案同時擔任網頁 favicon，因此「換掉 Blazor 圖片」與「修正網頁 Icon」是同一件事的兩面。
2. 該檔只有 32×32，卻被 CSS 放大到 88px 顯示（約 2.75 倍上採樣），實際畫面是模糊的。
3. Login 頁的品牌標並非圖檔，而是寫死在 `Login.razor` 的 inline SVG（綠色漸層方塊＋白色火花），屬於範本佔位美術，與 Splash 各自為政。
4. 兩頁標題與 `appsettings.json` 的 `SystemName` 三處各自寫死且都含「Blazor」字樣，改名需同時動三個地方。

## 變更範圍

### 一、新增品牌圖片

新增 `src/MyProject/MyProject.Web/wwwroot/images/brand-logo.png`（1024×1024）。

設計為**滿版構圖**：深色對角漸層底（`#0f172a` slate-900 → `#1e3a8a` blue-900 → `#2563eb`）搭配三層半透明等角菱形，呼應「模組化平台」語意。取色橋接兩頁既有配色 —— `#2563eb` 來自 Splash 的 accent、`#0f172a` 為 Splash 與 Login 共用的深色基底，因此在淺色 Splash 容器與深色 Login 玻璃容器上皆成立。

圖像本身無透明邊，配合 `object-fit: cover` 可完整填滿容器且不裁切主體。

### 二、網站圖示

以 ffmpeg 由 `brand-logo.png` 置中裁切縮放，覆蓋 `wwwroot/favicon.png`（Blazor 預設圖示就此移除）：

```bash
ffmpeg -i images/brand-logo.png   -vf "crop='min(iw,ih)':'min(iw,ih)',scale=64:64:flags=lanczos"   -pix_fmt rgba -y favicon.png
```

輸出改為 64×64（原 32×32），高 DPI 分頁不再模糊。

`Components/App.razor` 的引用同步改用 `@Assets["favicon.png"]`。**這是必要修正**：原本是裸相對路徑 `href="favicon.png"`，沒有 fingerprint，覆蓋舊檔卻不換 URL 會導致瀏覽器持續顯示快取中的舊 Blazor 圖示。同檔其他樣式表本就採用 `@Assets[...]`，改法一致。

### 三、Splash 與 Login 改用同一張圖並滿版

- `SplashView.razor`：`src="/favicon.png"` → `src="/images/brand-logo.png"`。
- `SplashView.razor.css`：`.splash-brand-image-wrap` 移除 `padding: 1rem`、加 `overflow: hidden`；`.splash-brand-image` 由 `width: 88px; height: auto` 改為 `width: 100%; height: 100%; object-fit: cover`。行動版（`max-width: 640.98px`）原本的 `width: 64px` override 因基礎規則已為 100% 而失去作用，一併移除。
- `Login.razor`：刪除 inline SVG（含 `linearGradient#brandGradient`），改為 `<img class="brand-logo-image" src="/images/brand-logo.png" />`；原 `aria-hidden="true"` 移除，改以有意義的 `alt` 提供替代文字。
- `Login.razor.css`：`.brand-logo` 加 `box-sizing: border-box` 與 `overflow: hidden`、移除 `padding: 12px`（原先無 border-box，實際佔用 132×132 而非宣告的 108×108，順帶修正）；`.brand-logo svg` 規則改寫為 `.brand-logo-image`，加上 `object-fit: cover`。

### 四、品牌名稱收斂為單一來源

`appsettings.json` 的 `SystemName` 與 `SystemDescription` 由「Blazor開發啟動範本專案」改為「企業管理平台」。

兩頁標題不再寫死，改為讀取設定值 —— `SplashView.razor.cs` 與 `Login.razor.cs` 各注入 `IOptions<SystemSettings>`（沿用 `MainLayout.razor.cs` 既有寫法）並公開 `SystemName` 屬性，razor 端綁定 `@SystemName`。

此後改名只需異動 `appsettings.json` 一處，Splash、Login 與「關於」對話窗三處自動同步。

> Login 頁為 `[ExcludeFromInteractiveRouting]` 靜態 SSR，`IOptions<T>` 注入於靜態渲染下同樣可用，不影響 `App.razor.cs` 既有的渲染模式判斷。
