# 「關於」對話窗移除「.NET 版本」（0.4.45）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.4.45
- 首次實作版本：0.4.45
- 最後核對日期：2026/08/27

## 目的

「關於」對話窗原本顯示七列系統資訊，其中「.NET 版本」會印出精確的執行階段版本
（例如 `.NET 10.0.11`）。

這個對話窗**任何已登入者都能開啟、不做權限過濾**（見 [首頁與導覽 PRD](../prd/首頁與導覽-prd.md) §五），
等於把精確的 runtime patch 版本公開給所有帳號 —— 對照公開的 CVE 清單就能判斷這台主機
有沒有套用修補，是不必費力就能取得的偵察情報。**本次移除屬安全考量，不是版面精簡。**

## 範圍（刻意只限一列）

只移除「.NET 版本」。「執行環境」「啟動時間」「已運作時間」**維持原狀**。

- 「執行環境」（顯示 `Development` / `Production`）在性質上屬同類資訊，開發時曾一併評估，
  但本次決定不擴大範圍。日後若要收斂，這是第一個候選。
- 「啟動時間」「已運作時間」會透露重啟／上版節奏，但對運維排錯有實際價值，予以保留。

移除後，PRD 中「內容僅為系統識別資訊，不含連線字串、金鑰或其他機敏設定」這句依然成立。

## 作法

`MainLayout.OnAboutClick` 的集合初始化中刪除一行：

```csharp
new(".NET 版本", RuntimeInformation.FrameworkDescription),
```

並**一併刪除檔案第 1 行的 `using System.Runtime.InteropServices;`** —— `RuntimeInformation`
在整個 repo 中只有這一處使用，該 using 因本次改動成為孤兒。專案開著
`TreatWarningsAsErrors`，留著會是雜訊；依開發慣例，自己的改動造成的孤兒 import 要自己清掉。

`MainLayout.razor` 的 `@foreach` 是資料驅動的，**不需要改**；方法上「已運作時間需在開啟當下
計算」的註解與其餘六列邏輯皆未動。

## 未改動

Razor 標記、Modal 寬度與樣式、其餘六列、資料庫（**無 migration**）。

亦**未回頭修改** `docs/changelog/2026-08-17-移除工作項目會議記錄與MSSQL支援.md` 中
「七列資訊……含 .NET 版本」的敘述 —— 那是 0.4.24 當時的歷史紀錄，不應改寫。
