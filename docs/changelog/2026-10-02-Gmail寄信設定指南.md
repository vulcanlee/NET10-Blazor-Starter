## 為什麼

[日誌與設定檔說明 §4.3.2.2](../operations/日誌與設定檔說明.md) 逐鍵說明了 `EmailSettings`，
但沒有說「要用某個 Gmail 帳號寄信時，每個值該填什麼、要到 Gmail／Google 帳戶網頁的哪裡取得」。
最常卡關的幾點都沒寫：Gmail 必須用應用程式密碼（需先開兩步驟驗證）、SMTP 主機與連接埠在 Gmail 網頁上看不到、
`FromAddress` 與登入帳號不同時寄件者會被改寫。

## 做了什麼

只改文件，程式沒有異動。

**新增 [Gmail 寄信設定指南](../operations/Gmail寄信設定指南.md)**
- 步驟一～二：在 Google 帳戶網頁開啟兩步驟驗證、產生應用程式密碼，以及找不到選項時的原因。
- 步驟三：對照表「設定鍵 → 要填的值 → 從哪裡取得」，標明 `Host`／`Port`／`Security` 是 Google 公布的固定值。
- 步驟四～五：`appsettings.json` 範例（不含帳密）；帳密放 User Secrets（開發機）或環境變數（正式機）。
- 步驟六：在「系統健康監控」驗證連線並寄出測試信，實際走一次忘記密碼流程。
- 疑難排解表（535／534／550 錯誤碼、連線逾時、憑證、寄件者被改寫、垃圾郵件）與安全提醒。
