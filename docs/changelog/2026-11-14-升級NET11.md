# 升級 .NET 11（0.10.14）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.10.14
- 首次實作版本：0.10.14
- 最後核對日期：2026/11/14

## 目的

使用者決定把專案從 .NET 10 升到 .NET 11（2026/11/10 正式發布），並導入能解決問題的新功能。專案與 repo 名稱沿用 NET10。
測試結果見 [測試報告](../migration/測試報告/升級NET11.md)。

## 變更內容

### 1. 框架與套件

| 項目 | 0.10.13 | 0.10.14 |

| 目標框架、SDK | `net10.0`、10.0.400 | `net11.0`、11.0.100（`global.json`） |
| ASP.NET Core、EF Core、Redis 快取 | 10.0.14 | 11.0.0 |
| AntDesign | 1.6.2 | 1.6.3-dotnet11.rc3（唯一替 net11.0 編譯的版本；預覽版，正式版釋出後更換） |

### 2. .NET 11 帶來的程式調整

- **新的 Blazor 分析器**：BL0016（JS 互通沒包 try/catch）— 錯誤頁的「回上一頁」補上例外處理，`TokenStore`、`BrowserFiles`、`FileDownload` 三個刻意把例外交給呼叫端的薄包裝以類別層級豁免並註明理由；BL0012（多餘的 `StateHasChanged`）— 移除兩處；BL0014 的分析器本身在側邊選單元件當掉（AD0001），人工確認四個 `@for` 迴圈都沒有捕捉迴圈變數後以 `NoWarn` 暫時關閉，註明解除條件。
- **`EditContext.Validate()` 已過時** → 六處與 CRUD 產生器樣板改成 `await ValidateAsync()`（也會執行 .NET 11 的非同步驗證器）。
- **`IStartupValidator` 已過時** → 改用 `IAsyncStartupValidator`（`Program.cs` 與 `OptionsValidationTests`）。

### 3. 採用的新功能

- **WASM 發佈瘦身**：.NET 11 為了 OpenTelemetry 把 WebAssembly 的計量、事件追蹤、HTTP 追蹤傳遞預設改成開啟；前端沒有用，在 `MyProject.Web.Client.csproj` 明確關掉（少約 150 KB）。Brotli 後 `_framework` 4,574,113 位元組（.NET 10 是 4,444,473，+2.9%，增加的是 .NET 11 執行階段本身）。
- **EF Core 11 `.config/dotnet-ef.json`**：預設 `project`、`startupProject`、`context`，在 repo 任何子目錄直接打 `dotnet ef migrations add 名稱`；EF Core 指令備忘與腳手架文件的指令一併簡化。
- **複刻腳本**：`New-StarterProject.ps1` 一開始檢查 dotnet-ef 的主版號與專案的 EF Core 相同，不符時中止並印出升級指令（`ScaffoldScriptConventionTests` 守門）。

### 4. AntDesign RC 的外觀變化

- **對話窗頁尾的按鈕順序**：RC 把預設頁尾改成「取消　儲存」（PR #4857）。這是使用者看得到的改變，這一版以 `OverlayStyles` 維持原本的「儲存　取消」（`ModalFooterOrderTests` 守門），**要不要採用新順序待使用者決定**（刪掉那段樣式即可）。
- 表單說明區與頁尾高度少幾個像素；按下工具列按鈕後滑鼠停在上面時提示框會再出現（一般懸停行為，不擋點擊）。

### 5. 檢查過、不受影響的不相容變更

表單自動 CSRF 檢查（只影響標了 antiforgery 的端點，本專案沒有）、Microsoft.OpenApi 3.x 與 OpenAPI 3.2 預設（沒有自訂篩選器、Swashbuckle 維持 3.0）、`BackgroundService` 例外時主機結束方式（四個背景工作都自己接住例外）、回應壓縮的 `Vary` 標頭與 zstd（本專案沒有用回應壓縮中介軟體）、`IAuthorizationRequirementData` 套用到 Controller（本專案沒有實作它的屬性）、C# 15 新的語境關鍵字（沒有撞名）。EF Core 模型與 migration 沒有差異。

## 升版注意

- 版本號 0.10.13 → 0.10.14。沒有資料庫異動、沒有設定異動。
- 🔴 **伺服器要安裝 ASP.NET Core 11 Hosting Bundle**（可與 10 版並存），CPU 至少 x86-64-v2；開發機與建置機要裝 .NET 11 SDK，dotnet-ef 全域工具要更新到 11 版。見[正式部署與安全檢查清單](../operations/正式部署與安全檢查清單.md)「執行環境：.NET 11」。
- Visual Studio 要更新到支援 .NET 11 的版本。
- 衍生專案升級：照上表換版本、跑一次建置，依編譯錯誤處理 BL0016／BL0012／`ValidateAsync`／`IAsyncStartupValidator`（做法見速查表 §6.33 第 116～125 點）；自訂了對話窗頁尾的衍生專案要注意第 124 點。
- 測試 3,184 → 3,188，品質關卡 7 步通過；實機與效能見測試報告。
