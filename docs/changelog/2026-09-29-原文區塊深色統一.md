# 原文區塊統一為深梅黑底＋等寬字：日誌檢視、健康監控、例外堆疊同一組（0.9.70）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.70
- 首次實作版本：0.9.70
- 最後核對日期：2026/09/29

## 為什麼

日誌檢視展開列的原始內容是淺粉底、一般字型，整行 nlog 文字擠在一起不好讀；深色底配等寬字，
欄位之間的 `|` 比較容易對齊。站內原本已有兩塊深色原文區，卻各自寫死不同色碼
（健康監控 `#1f1f1f` 深灰、例外堆疊 `#0f172a` 深藍黑），三處看起來像三個系統。

## 做了什麼

- **新色票**（`wwwroot/theme.css` 的 `:root`）：`--app-code-bg: #2a0f1d`（深梅黑，與側邊欄同色相）、
  `--app-code-text: rgba(255, 240, 246, 0.92)`（對底色約 15:1）、`--app-code-line`、`--app-code-font`（Consolas／Menlo 等寬）。
- **三處改用同一組 token**，並加 `color-scheme: dark` 讓超出高度時的捲軸也是深色；尺寸與圓角各自保留：
  - 日誌檢視展開列 `.log-view-raw`（`LogViewerView.razor.css`）
  - 系統健康監控日誌尾端 `.log-tail`（`SystemHealthPage.razor.css`）
  - 系統例外紀錄明細堆疊 `.exception-log-stack`（`OverlayStyles.razor`）
- **守門**：`ThemeConventionTests.PaletteHexes` 加入 `#2a0f1d`，確保它只住在 `theme.css`。
- **文件**：介面視覺設計規範的色票表與 §8.1、腳手架開發指引 §8.1 綠色系範例補上 `--app-code-*`、日誌檢視 PRD、頁面操作說明。

## 刻意不做的事

- 不改稽核紀錄明細（不是日誌原文）與 AI 報告裡 Markdown 的程式碼區塊（屬報告排版）。
- 不收斂 `LogLevelSettingView`／`DatabaseUsageView` 既有的 monospace 宣告。
