## 目的

《AI 對話紀錄 PRD》§六、§七的兩個限制：
- 只能用中繼資料（日期、作業、帳號、模型、關聯說明）找紀錄，不能搜尋內文。
- PDF 一次只能匯出一筆。

想找「AI 哪一次提到某件事」，或要把一整段 Agent 對話交給別人看時，只能一筆一筆開。

## 使用者的決定（2026/11/07）

| 項目 | 決定 |
|---|---|
| 搜尋方式 | 在篩選結果內逐檔掃描，不另建索引：內文仍只存在專屬內容檔，不進資料庫，也不會跟著資料庫進備份 |
| 比對範圍 | 畫面看得到的文字：「完整對話」的每則訊息與 AI 回答；失敗而沒有回答時改比對錯誤內容 |
| 合併匯出 | 三種入口都做：清單勾選多筆、明細窗「整段對話」、目前篩選結果全部 |

## 內容

### 內文搜尋

- 工具列新增「內文關鍵字」。有填時，按「查詢」或「重新整理」會呼叫 `AiCallLogService.FindContentMatchesAsync`：
  1. 先套用其他篩選，依送出時間由新到舊取最多 `ContentScanLimit`（1,000）筆。
  2. 逐一讀內容檔比對，不分大小寫。
- 比對對象：
  - 每則送出的訊息（`AiCallLogMessages.Parse`）與回應文字。
  - 沒有回應文字（失敗）時，改比對原始回應（錯誤 body）。
  - 原始 JSON 的欄位名稱不算；內容檔不存在的略過。
- 掃描結果以 Id 清單交給查詢（`AiCallLogQuery.Ids`），換頁、排序、CSV 與 PDF 匯出都用同一份清單，不重新掃描。
- 清單上方顯示「內文搜尋「…」：掃描 N 筆，符合 M 筆。」；超過 1,000 筆時加註只掃描最新的、請縮小範圍。
- 稽核 `AiCallLog.Search` 多一個條件 `content`：原文只進詳細內容檔，摘要只記有沒有填。
- 掃描在背景執行緒進行，離開頁面時取消；掃描期間停用「查詢」「重新整理」。
- 搜尋之後又改了條件卻沒按「查詢」：清單上方提示結果已過期，匯出 CSV／PDF 前先請使用者重新查詢。

### 合併匯出 PDF

- 三個入口共用 `AiCallLogMergedPdfExport`：
  - 清單勾選後出現「合併匯出 PDF（N）」，在「刪除選取」右邊。
  - 明細窗在同一段對話有兩筆以上時出現「匯出整段對話 PDF（共 N 次呼叫）」。
  - 工具列「匯出目前查詢結果（PDF，最多 50 筆）」，有內文搜尋時只含符合的。
- `AiCallLogPdfBuilder.BuildMerged` 的版面：
  - 開頭：標題「AI 對話紀錄（共 N 筆）」，系統、產生時間、匯出者、筆數、送出時間範圍，免責說明，以及索引（序號、送出時間、作業、發起者、結果）。
  - 之後每筆換頁一節：中繼資料加完整對話，依送出時間由舊到新。
- 上限：
  - 一次最多 50 筆，超過時畫面提示縮小範圍；產生器也會拒絕，只是保險。
  - 每段內容最多 5 萬字元，整份最多 100 萬字元，超過時註明「完整內容請開啟單筆紀錄或下載 JSON」；單筆 PDF 維持 20 萬字元。
- 內容檔不存在的那一筆仍列入，註明只有中繼資料。
- 稽核沿用 `AiCallLog.Export`，記 `format=pdf-merged; source=selected|conversation|query; rows=N`；匯出了哪幾筆（`ids=…`）放在稽核的詳細內容檔，不記內容。

## 獨立審查

另派一個代理人只看程式差異，結果沒有高嚴重度問題，也沒有內文寫進資料庫、日誌或稽核摘要。處理如下：

| 發現 | 處理 |
|---|---|
| 內文搜尋逐檔讀取與解析跑在畫面連線的執行緒上，掃 1,000 筆大檔會卡住畫面，離開頁面也停不下來（中） | 方法加 `CancellationToken` 並全程 `ConfigureAwait(false)`，畫面以 `Task.Run` 呼叫、離開頁面（Dispose）時取消。新增測試 |
| 掃描中可以再按「查詢」，兩次掃描互相覆蓋，說明列與清單可能對不上（中） | 掃描期間停用「查詢」「重新整理」，處理常式也擋下；說明列顯示「正在逐筆比對內容檔…」 |
| 整段 Agent 對話每次都重送歷史，合併 PDF 的內容隨呼叫次數平方成長，只限每段不夠（中） | 加整份 100 萬字元的預算（`MergedContentBudget`），用完後的段落只留註明。新增測試 |
| 改了條件沒按「查詢」，舊的符合清單仍和新條件取交集（低） | 記下搜尋時的條件，不同時提示「條件已變更」，匯出 CSV／PDF 前先請使用者重新查詢 |
| 請求解析不出訊息時整段請求沒被搜尋；成功但只有工具呼叫的回應退回比對原始 JSON，搜 `function` 幾乎每筆都中（低） | 解析不出時比對原始請求；只有呼叫失敗才比對原始回應。新增測試 |
| 合併匯出的稽核看不出匯出了哪幾筆（低） | 紀錄 Id 清單放進稽核的詳細內容檔，摘要不變 |
| 內容檔損毀時 PDF 寫成「內容檔不存在」（低） | 文案改成「內容檔不存在或無法讀取（…或檔案損毀）」 |
