# 決定紀錄：三項待辦經決定不納入實作範圍（0.4.23，無版本變更）

## 目的

權限重構（階段 0～5）完成後，尚有三項獨立待辦。經決定**不納入目前實作範圍**——為明確決定、非遺漏。本次把相關文件措辭從「待辦／暫緩／後續待辦」更新為「經決定不實作／超出範圍」，讓未來讀者知道是刻意不做，並保留「日後有實際需求再另案評估」的彈性。**純文件、無程式碼變更、不改版本號。**

## 決定內容（2026/07/09）

| 項目 | 決定 | 保留現況 |
|------|------|----------|
| Refresh Token 落庫撤銷 | 不實作 | 維持 stateless JWT、不落庫、不可撤銷（接受此已知限制） |
| MFA（TOTP）強制 | 不實作 | TOTP 骨架保留、預設關閉；不做 QR 綁定 UI 與登入第二步強制 |
| SQL Server 遷移軌道 bootstrap | 不實作 | 以 SQLite 為預設且唯一受支援執行資料庫；SqlServerMigrations 維持只有 marker |

共同框架：**刻意不做、非遺漏；日後有實際客戶／營運需求再另案評估**。
