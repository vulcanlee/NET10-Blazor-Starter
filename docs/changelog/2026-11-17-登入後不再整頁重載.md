# 登入後不再整頁重載、登出卡片說「已登出」（0.10.35）

- 文件版本：1.1
- 文件狀態：已實作
- 現行系統版本：0.10.35
- 首次實作版本：0.10.35
- 最後核對日期：2026/11/17

## 目的

使用者 2026/11/17 回報：已經開過網頁的人按「登出」會看到啟動卡片，接著重新登入又看到一次，而且卡片寫著「第一次開啟需要下載程式，之後會更快」，像是程式又被重新下載了一次；第二次的卡片還出現「100%」但進度條只到八成。

## 原因

- 登出（`ClientSession.LogoutAsync`）與登入成功（`Login.razor.cs`、`TwoFactor.razor.cs`）都以 `forceLoad: true` 整頁載入，.NET 執行環境重新啟動一次，所以兩次都看到 `index.html` 的啟動卡片。檔案來自快取，百分比一下子就到 100%。這是 Blazor Server（登入 Cookie）時代沿用下來的做法。
- 卡片的「第一次開啟」提示是固定文字，不分是不是第一次。
- Blazor 同時設定進度條寬度與百分比文字（同一個數值），但進度條有 0.2 秒的寬度動畫：最後一個檔案下載完後，瀏覽器主執行緒忙著啟動 .NET，動畫停在半途。
- 第一輪修正後使用者實測「似乎沒有改變」，量測發現：登入確實不再整頁載入，但換頁後外框要確認身分（`/me`）、一個接一個讀系統資訊與選單，期間顯示外觀幾乎相同的「正在確認登入狀態…」卡片（開發模式 0.3～0.6 秒）；登出仍整頁載入（開發模式約 1.5 秒）。

## 決定（使用者選定）

- **登入成功不再整頁重載，也不再出現任何卡片**：按鈕顯示「登入中…」，在登入頁就確認身分、讀好外框資料，再在程式內換頁。登入頁一定是剛整頁載入的（登出、Token 失效、未登入導過來都整頁載入），記憶體裡沒有任何使用者的資料。
- **登出維持整頁重載**（把這位使用者留在記憶體的身分、選單、權限、推播連線與畫面資料清乾淨，共用電腦時下一位看不到），但卡片改說「已登出，正在回到登入頁…」、不顯示百分比，看起來是登出的過程，而不是程式重新初始化。
- **這個瀏覽器成功啟動過，就不再顯示「第一次開啟」提示**；進度條的動畫拿掉。

## 變更內容

- `Auth/ClientSession.cs`：
  - `EnterAfterSignInAsync(returnUrl, prepareShell)`：以 `InitializeAsync` 確認身分（成功才呼叫 `prepareShell` 讀外框資料），再經 `ReturnUrlGuard` 程式內換頁。`InitializeAsync` 已經導走（必須改密碼、設定兩步驟驗證、沒有主要角色）時不再導；連不上或被限流照樣導過去，由外框處理。
  - `SignedInAsync` 記下「登入前這個程式是否已載入過某位使用者」（`Info` 有值，例如從登入後的畫面以程式內連結到了登入頁）；是的話照舊整頁載入、不預先讀取。
  - `LogoutAsync` 在這個分頁的 sessionStorage 寫一次性記號 `app.signedOut`（`SignedOutMarkerKey`）再整頁載入；註解寫明為何仍整頁載入。
- `Layout/ClientShellData.cs`（新）：系統資訊與選單同時讀（`LoadAsync`）；登入頁 `PrepareAsync` 先讀好，外框 `TakePrepared` 拿一次。
- `Layout/ClientMainLayout.razor.cs`：`Session.Info` 有值又拿到先讀好的資料時直接用、不再確認第二次；否則照舊 `InitializeAsync` 後再讀。側邊選單狀態在瀏覽器以 `IJSInProcessRuntime` 同步讀，用先讀好的資料時整個初始化沒有非同步等待，第一次渲染就是完整外框。
- `Views/Auths/Login.razor(.cs)`、`TwoFactor.razor(.cs)`：改呼叫 `EnterAfterSignInAsync`；處理中按鈕顯示「登入中…」。
- `wwwroot/js/loading-hint.js`（新，排在 `index.html` 的 `<head>`；外部檔因為 CSP 只允許 import map 行內）：
  - localStorage 的 `app.loadedBefore` 是 `1` 就在 `<html>` 加 `app-loaded-before`；卡片被 Blazor 取代（成功啟動）才寫入，啟動失敗時不寫。
  - sessionStorage 有 `app.signedOut` 就刪掉、在 `<html>` 加 `app-signed-out`；畫面上不再有任何載入卡片（登入表單出來）就拿掉。
- `wwwroot/index.html`、`Commons/ClientLoadingScreen.razor`：加上隱藏的「已登出，正在回到登入頁…」（登入頁讀設定時的卡片接續同一句，不會跳成「正在載入…」）。
- `wwwroot/app.css`：`.app-loaded-before .app-loading-hint` 隱藏；`app-signed-out` 時顯示已登出那句、隱藏百分比那行與提示；拿掉 `.app-loading-bar-fill` 的 `transition` 與只為它存在的 `prefers-reduced-motion` 區塊。
- `Program.cs`：註冊 `ClientShellData`。
- 不動：Token 失效回登入頁、強制改密碼／設定兩步驟驗證、改密碼與兩步驟驗證設定完成後的整頁載入。

## 測試

- `ClientSessionTests`：`EnterAfterSignIn_InAFreshlyLoadedApp_ShouldPrepareTheShellAndNavigateWithoutAFullLoad`（含站外網址回 `/App`，外框資料在換頁前讀好）、`EnterAfterSignIn_AfterAUserWasLoaded_ShouldStillDoAFullLoad`、`EnterAfterSignIn_WhenSetupIsForced_ShouldLeaveItToTheSessionCheck`、`EnterAfterSignIn_WhenTheServerCannotBeReached_ShouldStillNavigate`、`ShellData_ShouldLoadInfoAndMenu_AndHandThePreparedCopyOutOnlyOnce`；登出測試補「寫下已登出記號」。
- `LoginPageTests`：登入成功不整頁載入（改名 `..._WithoutAFullLoad`），換頁前已確認身分、讀好外框資料。
- `LoadingAndStatusPageTests`：`LoadingBar_ShouldNotAnimateItsWidth`、`FirstDownloadHint_ShouldOnlyShowUntilTheAppHasStartedOnce`、`LoadingCard_AfterSignOut_ShouldSaySignedOut`。
- `PageAuthorizationTests.ClientMainLayout_ShouldRenderNothingUntilTheSessionIsInitialized`：閘門規則改寫成「沒有登入頁先讀好的資料（且 `Session.Info` 有值）時必須先 `InitializeAsync`、失敗就停止；`isAuthenticated` 只在之後設為 true」。規則本身不放寬：唯一的例外是登入頁已經以同一個 `InitializeAsync` 確認成功。

## 實機驗證

以 `Start-E2EHost.ps1` 的隔離網站（全新資料庫），暫存的 playwright 腳本（不進 repo）操作，逐格記錄畫面上出現的卡片與文字：

- 第一輪（發佈版，11 項全部通過）：第一次開啟有「第一次開啟…」、之後沒有；登入前在頁面放的標記登入後還在（沒有整頁載入）；登出整頁載入；百分比到 100% 之後進度條都是滿的；帶 `returnUrl=/Profile` 登入導到原頁；重新整理沒有提示。
- 第二輪（開發模式，連續登入登出兩輪）：
  - 登入：只有按鈕從「登入系統」變成「登入中…」（0.5～1.1 秒，含伺服器剛啟動），接著直接是 `/App` 的完整畫面，**沒有任何載入卡片**。
  - 登出：整頁載入，卡片從頭到尾都是「已登出，正在回到登入頁…」（約 1.4～1.6 秒，接著登入頁讀設定 0.1 秒同一句），登入表單出來後 `<html>` 只剩 `app-loaded-before`。
  - 第一輪的 11 項重跑全部通過。
- 兩步驟驗證頁沒有實機走過（呼叫同一個 `EnterAfterSignInAsync`，由單元測試涵蓋）；修正前「100% 但進度條只到八成」沒有在本機重現，原因依 Blazor 設定兩個變數的程式碼判斷。
