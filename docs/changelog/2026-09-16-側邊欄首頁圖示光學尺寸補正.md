# 側邊欄「首頁」圖示做光學尺寸補正（0.9.15）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.15
- 首次實作版本：0.9.15
- 最後核對日期：2026/09/16

## 起因

使用者回報：

> 這裡的房子圖示，與其他圖示相比，好像有些小

字級其實完全一樣（全部 24px），問題出在字面本身。

## 量過才動

把側邊欄這組圖示在 100px 字級下畫到 canvas，逐像素量墨跡的外接矩形高度：

| 字面 | 墨跡高度 |
|---|---|
| `admin_panel_settings` | 84 |
| `work` | 80 |
| `analytics` | 76 |
| `logout` | 76 |
| **`home`** | **72** |
| `storage` | 68 |

`home` 比鄰居矮 8～12px（約 10～15%）。它是個尖頂三角形、上半部又細，
所以即使 em 方框一樣大，看起來就是小一號。

> `storage` 更矮（68），但它是三條滿版橫槓、視覺密度夠，不需要補。
> **這就是為什麼要量「墨跡高度 ＋ 實際外觀」兩者，不能只看數字自動套公式。**

## 也試過換字面

| 候選 | 墨跡 | 結論 |
|---|---|---|
| `house` | 84×72 | 跟 `home` 一樣高，多一道門，沒解決問題 |
| `home_filled` | 84×72 | 同上 |
| `cottage` | 92×84 | 高度對了，但多一根煙囪、整體偏寬，比鄰居大且不對稱 |
| `other_houses` | 92×76 | 兩棟房子，語意不是「首頁」 |

沒有「更高的房子」可換，所以改走光學補正：**同一個字面，只把尺寸調到視覺對齊**。

## 變更內容

### 新增

`MyProject.Web/Components/Layout/MaterialIconOpticalSize.cs` —— 一張很小的補正表，
目前只有 `home => 27`（基準 24）。量測數字與判斷理由都寫在類別的 XML 註解裡。

### 修改

`NavMenu.razor`（收合側邊欄的觸發鈕、飛出子選單、收合連結共 3 處）與
`SidebarMenuNode.razor`（展開側邊欄的 SubMenu 標題與 MenuItem 共 2 處），
都改成 `Size="@MaterialIconOpticalSize.For(...)"`。

## 為什麼不用 CSS

⚠️ **`MaterialIcon` 會輸出行內的 `style="font-size:24px;"`，CSS 的 `font-size` 蓋不過去。**
補正只能從元件的 `Size` 參數走。

> 附帶發現（**本次未動**）：`NavMenu.razor.css` 裡那幾組給 `.material-icons*` 設
> `font-size: 1.25rem` / `1rem` / `1.1rem` 的規則，全部被行內樣式壓過，實際上是無效的 ——
> 所有側邊欄圖示的 computed font-size 都是 24px。日後要調圖示大小請改 `Size`，
> 改那些 CSS 不會有任何效果。
