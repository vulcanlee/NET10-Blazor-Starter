# 登入紀錄來源 IP 與稽核 IP 篩選（0.9.123）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.123
- 首次實作版本：0.9.123
- 最後核對日期：2026/10/12

## 起因

使用者希望個人資料頁「最近 20 筆登入紀錄」與稽核紀錄頁看得到使用者的來源 IP。

- 稽核紀錄頁 0.9.117 起已有「來源 IP」欄（清單、明細窗、CSV），使用者看到的是 0.9.117 之前的版本，重新部署即可。
- `AuditLog.ClientIp` 0.9.117 起已經記下每一筆登入的 IP，只是個人資料頁與首頁「上一次登入」沒有讀出來。

決定（2026/10/12）：個人資料頁登入紀錄與首頁「上一次登入」都顯示 IP；稽核紀錄頁另加「來源 IP」篩選。

## 異動

| 位置 | 改版後 |
|---|---|
| `ProfileService` | `LoginRecord` 加 `ClientIp`；`GetRecentLoginsAsync`、`GetPreviousLoginAsync` 帶出 IP |
| `ProfileView.razor(.css)` | 登入紀錄表改為「時間、動作、來源 IP、結果」，沒有 IP 顯示「—」；長的 IPv6 允許換行 |
| `MyAccountWidget.razor` | 「上一次登入」在登入方式後面顯示 IP（有值才顯示） |
| `AuditLogQuery`、`AuditLogQueryService` | 新條件 `ClientIp`：前綴比對（去頭尾空白），沒有 IP 的舊紀錄不符合；清單與匯出 CSV 共用 |
| `AuditLogView.razor(.cs/.css)` | 「操作者帳號」下方加「來源 IP」輸入框 |
| 操作說明 | `profile.md`（欄位、檢查帳號情境）、`app.md`（我的帳號）、`audit-logs.md`（查詢條件） |
| 文件 | 個人資料、首頁儀表板、稽核紀錄 PRD；畫面與欄位字典 |

## 測試與驗證

- `AuditLogQueryServiceTests`：IP 前綴比對（`203.0.113` 命中兩筆、前後空白忽略、`0.113` 不命中中段、沒有 IP 的舊紀錄不出現）。
- `ProfileTests`：登入紀錄帶出 IP，舊紀錄為 null。`DashboardTests`：「我的帳號」顯示上一次登入的 IP。
- 實機（暫存資料目錄＋全新資料庫，Playwright 驅動 Edge）：
  - 首頁「上一次登入 2026-10-12 15:50 帳號密碼 ::1」。
  - 個人資料頁表頭「時間 動作 來源 IP 結果」，每列 `::1`；390px 寬無水平捲動。
  - 稽核紀錄「來源 IP」輸入 `::1` → 4 筆（全部），匯出 CSV 4 筆、最後一欄都是 `::1`；輸入 `10.` → 0 筆。

`SystemVersion` 由 `0.9.122` 遞增為 `0.9.123`。
