# 修正 Pkcs 弱點造成的還原失敗（0.9.126）

- 文件版本：1.0
- 文件狀態：已實作
- 現行系統版本：0.9.126
- 首次實作版本：0.9.126
- 最後核對日期：2026/10/15

## 起因

使用者用 VS 2026 建置時，`MyProject.Web` 與 `MyProject.Tests` 還原失敗：

```text
error NU1902: 套件 'System.Security.Cryptography.Pkcs' 10.0.0 具有已知的 中度 嚴重性弱點，https://github.com/advisories/GHSA-2fmv-rv2c-59x7
error NU1903: 套件 'System.Security.Cryptography.Pkcs' 10.0.0 具有已知的 高 嚴重性弱點，https://github.com/advisories/GHSA-846f-f764-76mx
```

核對結果：

- 這兩則是 2026-10-13 發布的 .NET 阻斷服務（DoS）弱點（CVE-2026-70162、CVE-2026-84008），受影響 `10.0.0 ~ 10.0.12`，修補版 `10.0.13`。程式碼沒有變動，是新公告讓原本能建置的專案開始失敗。
- 引入路徑：`MailKit` 4.18.0 → `MimeKit` 4.18.0 → `System.Security.Cryptography.Pkcs` 10.0.0。`MimeKit` 最新版 4.18.1 仍相依 10.0.0，升級 MailKit 沒有效果。
- `Directory.Build.props` 的 `TreatWarningsAsErrors` 刻意讓 `NU1901`～`NU1904` 維持 error，所以還原直接失敗；與 VS 版本無關，`dotnet build` 結果相同。

決定（2026/10/15）：只直接參考修補版 10.0.13 覆蓋遞移版本；不一併升級 `Microsoft.*` 10.0.5 套件，也不用抑制。

## 異動

| 位置 | 改版後 |
|---|---|
| `src/MyProject/Directory.Packages.props` | 新增 `System.Security.Cryptography.Pkcs` 10.0.13，註解寫明原因與移除條件 |
| `src/MyProject/MyProject.Web/MyProject.Web.csproj` | 直接參考 `System.Security.Cryptography.Pkcs`（會流向 `MyProject.Tests`）|
| 文件 | CI-CD 與品質檢查新增 §4.3（含移除條件）、§4 的 MailKit 說明補上現況 |

`Invoke-QualityGate.ps1` 的允許清單不需變動：覆蓋後這兩則諮詢不會再出現。

**移除條件**：`MailKit`／`MimeKit` 改為相依 Pkcs ≥ 10.0.13 後，升級 MailKit，並移除上述兩處。

## 驗證

- `dotnet build src/MyProject/MyProject.slnx`：0 警告、0 錯誤；`MyProject.Web` 與 `MyProject.Tests` 的 `project.assets.json` 都解析為 `System.Security.Cryptography.Pkcs/10.0.13`。
- `pwsh ./scripts/Invoke-QualityGate.ps1`：建置、格式、測試、文件編碼、弱點掃描全部通過（弱點掃描只剩允許清單中的 `GHSA-2m69-gcr7-jv3q`）。
