## 官方費率核對

依 [AI 模型計費更新指南](../operations/AI模型計費更新指南.md) 情況 B（新增模型）辦理。以下為 OpenAI API Standard 每百萬 token 的美元價格；長脈絡分級在單次請求的輸入 token **超過 272,000** 時對整筆請求生效。

| 模型 | 一般：輸入／快取輸入／輸出 | 長脈絡：輸入／快取輸入／輸出 |
|---|---|---|
| `gpt-6.1-sol` | 2／0.1／10 | 4／0.2／15 |

模型頁（長脈絡寫作「2x input 與 cache、1.5x output」）與定價頁（Long context >272K：4.00／0.20／15.00）數字一致。新增 `gpt-6.1-sol` 至 `AiPricingSettings:Models`（置於 `gpt-6-astra` 與 `gpt-6-sol` 之間），`AiPricingSettingsTests` 同步釘住一般與長脈絡費率，文件中的模型總數由十二改為十三。`SystemVersion` 由 `0.9.73` 遞增為 `0.9.74`。

注意 `gpt-6.1-sol` 的快取輸入單價（0.1）與 `gpt-6-sol`（0.2）不同；兩者為各自獨立的鍵，受限前綴比對不會互相套用。其餘 GPT-6 模型核對後價格不變，`models/all` 上現有十二個鍵均未標為 Deprecated。

模型頁另列 Cache writes $2.5，依指南不支援（`usage` 無法區分），未抄錄。

來源：[GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[OpenAI API 定價](https://developers.openai.com/api/docs/pricing)、[全部模型](https://developers.openai.com/api/docs/models/all)。

本費率表估算 OpenAI API Standard 文字 token 費用。現有用量資料無法可靠區分 cache writes、Batch、Flex 或 Fast 模式；若透過 Azure OpenAI 使用，仍須對照實際供應者帳單。
