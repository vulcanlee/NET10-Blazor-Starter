## 起因

使用者的原話：

> 我需要一個 Token 用量明細，用來觀察這個系統對 LLM API 使用的情況……
> 我的目的在於想要知道對於各種 LLM API 究竟用在甚麼地方，使用了多少 Token，
> 以及可以統計與篩選出統計量。

並附上另一個系統的六張參考截圖（19 個作業、8 個模型、1213 筆明細）。

## 先講清楚的落差

| 參考系統 | 這個腳手架（改造前） |
|---|---|
| 19 個作業、8 個模型、1213 筆明細 | **只有一個 LLM 呼叫點**：日誌檢視頁的 AI 分析 |
| — | 原始回應 JSON 解析完就丟掉（區域變數） |
| — | **沒有任何用量資料表**；用量只以中文字串寫進 `AuditLog.Detail`，無法聚合 |

所以參考截圖的規模在這裡重現不了。使用者確認後採取的作法是：**把基礎設施做完整**，
讓日後每新增一個 LLM 呼叫點，只要呼叫一行就自動入帳並長出統計，與 0.9.11 的「系統例外紀錄」同一思路。

## 三個關鍵決定

**一、記錄點放在發出 HTTP 的那一層，不是畫面層。**
`AiLogAnalysisService.AnalyzeAsync` 裡才握有原始 `usage`、實際模型名稱與耗時；
回到 `LogViewerView` 之後這些全部已經丟失。失敗分支（空回應有用量、逾時／傳輸失敗無用量）
也都在這一層，才記得全。

**二、只存 `usage` 子物件，絕不存提示詞與回應內文。**
本專案唯一的 LLM 呼叫是 AI 日誌分析，它的**提示詞就是整份日誌內容**。存進來等於繞過日誌檢視頁的
管理員限制，也會破掉既有的「稽核紀錄不得寫入日誌內容或 AI 輸出」紅線。
`AiChatResponseParser.ExtractUsageJson` 因此只切出 `usage` 那一段。

**三、不做佇列與背景寫入器。**
與例外紀錄不同：LLM 呼叫是使用者主動觸發、一次數秒到數分鐘，多一次幾毫秒的資料庫寫入可忽略。
直接 `await`，全程 try/catch，記錄失敗絕不影響分析結果。

## 順帶修掉的一個既有問題

0.9.14 之前，PDF 匯出會拿同一份分析結果**再寫一筆帶相同用量數字的 `AuditLog`**。
若有人拿 `AuditLog` 做成本加總，同一次呼叫會被算兩次。記錄點改在 service 內之後，
只會記真正發出 HTTP 的那一次。（`AuditLog` 本身的寫入未動，那是業務稽核，分工不同。）

## 實作時踩到的三件事

### 1. `LoggingConventionTests` 兩次擋下

- `TokenUsageRawStore` 被要求必須注入 `ILogger` —— 它**不在**記錄管線內（與例外紀錄的
  `ExceptionStackFileStore` 不同，後者用 `ILogger` 會遞迴），所以是真的補一個 logger，不是加豁免。
- `Diagnostics/TokenUsageFormat.cs` 是純函式的靜態格式化類別，沒有可記的事，列入豁免清單並註明理由。
- 該測試同時**禁止日誌佔位符出現 `token` 字樣**，這也是欄位叫 `InputCount` 而非 `InputTokens` 的原因。

### 2. 在 `ExternalFileSystem` 新增路徑，必須同步改整合測試

0.9.11 的 `ExceptionPath` 就是漏了這一步，整合測試把檔案寫進開發者的真實目錄留下孤兒檔。
這次**在寫程式的同時**就把 `TokenUsagePath` 加進 `ApiIntegrationTests.CreateSettings()`，沒有再踩。

### 3. 匯出的 CSV 其實沒有 BOM

程式寫的是 `new UTF8Encoding(encoderShouldEmitUTF8Identifier: true).GetBytes(...)`，註解也寫著
「加 BOM，否則 Excel 開啟繁體中文會亂碼」—— 但 **`GetBytes` 不會輸出前導碼**，那個旗標只影響
`GetPreamble()` 與 `StreamWriter`。實跑抓下位元組才發現檔頭是 `E6 99 82`（「時」）而不是 `EF BB BF`。
已改成把 `GetPreamble()` 接在前面。

> ⚠️ 同樣的寫法也出現在 `LogViewerView.razor.cs:254` 與 `ExceptionLogView.razor.cs:326`，
> 那兩處不在本次範圍內，**尚未修正**。

### 4. 四個統計頁籤把整頁撐寬

`TokenUsageGroupTable` 的 `<div class="token-usage-table-wrap">` 套不到樣式 ——
Blazor 的 scoped CSS 以元件為界（`b-xxxx` 屬性），`TokenUsageView.razor.css` 的規則到不了子元件。
400px 下整頁 `scrollWidth` 是 823px。已補上 `TokenUsageGroupTable.razor.css`，
修正後三種寬度都是 `scrollWidth === clientWidth`。

### 5. `.razor` 的 `<style>` 裡 `@media` 要寫成 `@@media`

AntDesign 的 Modal 渲染在元件 DOM 之外，scoped CSS（連 `::deep`）打不到，
明細窗的樣式只能放 `FormModalHelper.razor` 的全域 `<style>`；
而該處直接寫 `@media` 會被 Razor 當成 C#，編譯錯誤 `名稱 'media' 不存在`。
兩點都是 0.9.12 踩過的坑，已寫進 PRD。
