## 改名待辦
- [x] 可使用 `scripts/New-StarterProject.ps1 -ProjectName 新系統代號 -DestinationPath 目標目錄` 產生新專案副本（0.9.1 起會保留 `docs/*.md` 的 BOM、自動產生新的 `UserSecretsId`，並確實排除 `bin`/`obj`/`.vs`）。
- [ ] 替換 solution、project、namespace 與 assembly 名稱，例如 `MyProject` 改成新系統代號。
- [ ] 檢查 `src/MyProject/MyProject.slnx` 內所有 project path 是否同步更新。
- [ ] 逐條核對高風險字串清單（`App.razor` 的 `*.styles.css`、`InternalsVisibleTo`、NLog 命名空間、Swagger 標題、外部登入 Cookie 名稱、`NavMenu` 硬編品牌、Redis `InstanceName`、Migration snapshot 內的 entity 字串）—— 見上手指南 §7.3。
- [ ] 更新 `appsettings.json` 的 `SystemSettings:SystemInformation`，包含系統名稱、描述與版本。
- [ ] 更新 README、docs、CI workflow 與 `.vscode/*.json` 內的顯示名稱與路徑。
- [ ] 檢查 UserSecretsId、NLog 路徑、資料庫檔案路徑、`BootstrapSettings` 與部署環境 secret。
- [ ] 更換品牌圖檔 `wwwroot/images/brand-logo.png` 與 `wwwroot/favicon.png`（二進位檔，文字取代不會處理）。

## API 與 DTO 待辦
- [x] Web API request/response 使用 DTO，不直接暴露 Entity。
- [x] 所有 API 回應統一封裝為 `ApiResult<T>`。
- [x] 可使用 `scripts/New-CrudModule.ps1 -Name 模組名稱` 產生 CRUD 模組骨架。
- [ ] 新增業務模組時，同步建立 `CreateUpdateDto`、`Dto`、`SearchRequestDto` 與 mapping。
- [ ] 新 API 優先使用 `/api/v1/...`，並保留 `/api/...` 相容路由直到公告移除。

## 驗收標準
- [ ] `dotnet build src/MyProject/MyProject.slnx -v:minimal --no-incremental` 成功。
- [ ] `dotnet test src/MyProject/MyProject.slnx` 成功。
- [ ] `dotnet format src/MyProject/MyProject.slnx --verify-no-changes` 無差異。
- [ ] `pwsh ./scripts/Test-DocsEncoding.ps1` 通過（`docs/` 全數 UTF-8 含 BOM）。
- [ ] Swagger UI 可使用 Bearer token 呼叫受保護 API。
- [ ] 新專案文件不再殘留不應公開的開發帳號、JWT key 或舊系統名稱。
