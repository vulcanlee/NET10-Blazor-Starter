# 分類清單

維護「分類」主檔：**新增、修改、停用分類**，並指定**哪些團隊可以使用**它；分類會出現在專案項目的分類下拉選單裡。

### 一分鐘看懂這一頁

- **解決什麼問題**：統一管理專案可以使用的分類名稱，避免每個人各自打字造成同一件事有好幾種寫法。
- **誰會用到**：負責整理資料定義的同仁或管理員；能不能新增、修改、刪除，依你角色的分類清單權限而定。
- **它在系統的哪個位置**：側邊選單「資料定義」群組底下；這裡建好的分類，是專案項目編輯窗與分類過濾器的選項來源。
- **開始前要準備**：想限定使用範圍時，先確認對應的團隊已經在團隊清單建好並啟用，才能在「適用團隊」選到它。
- **做完會得到**：一個可以在專案項目中選用的分類，並且只有適用團隊的成員會在下拉選單裡看到它。
- **它不做什麼**：不會決定專案的可見範圍（那是專案上的團隊欄位），也不會回頭修改已經掛了這個分類的既有專案。

## 一、功能摘要

這一頁以清單呈現你看得到的分類，每頁 8 筆，預設依更新時間由新到舊排序。你可以新增、修改、刪除分類（依權限顯示），也可以用關鍵字搜尋名稱與描述。每個分類可以指定多個適用團隊，也可以用開關切換啟用或停用。分類名稱在整個系統中不可重複，比對時會忽略前後空白與英文大小寫。

## 二、這個頁面在做什麼

分類有一個「適用團隊」欄位，它的**留空語意和專案相反**，這是最容易搞錯的地方：

| 畫面 | 團隊欄位留空的意思 |
|---|---|
| 專案項目的「團隊」 | 這筆專案公開給所有人看 |
| 分類清單的「適用團隊」 | **所有團隊都能使用這個分類**（視同公用分類） |

指定了適用團隊時，只有屬於其中任一團隊的人，才會在專案的分類下拉選單、以及**這份分類清單本身**看到它。也就是說，只限其他團隊使用的分類，你在這一頁是看不到的。

有兩種人不受這個過濾影響，看得到全部分類：管理員，以及沒有任何團隊的使用者。分類的團隊過濾只是讓下拉選單更精簡的便利設計，真正決定能做什麼的是角色權限。

適用團隊同樣是用**團隊名稱**比對。團隊改名後，分類上記的仍是舊名稱，不會自動更新。

## 三、畫面上有哪些按鈕、各自做什麼

### 工具列

| 按鈕／欄位 | 做什麼 | 何時出現 |
|---|---|---|
| 「新增」 | 開啟「新增分類」對話窗 | 有分類清單的新增權限才出現 |
| 「重新整理」 | 重新讀取清單，並顯示「已更新最新資料」 | 一律出現 |
| 「請輸入搜尋關鍵字」 | 輸入關鍵字，比對名稱與描述 | 一律出現 |
| 「清空搜尋」 | 清掉關鍵字並回到第一頁 | 搜尋框有文字時才出現 |
| 「搜尋」 | 依關鍵字重新查詢並回到第一頁 | 一律出現 |

### 清單欄位

| 欄位 | 意思 |
|---|---|
| 名稱 | 分類名稱，可排序 |
| 描述 | 說明這個分類用在哪裡 |
| 適用團隊 | 可以使用這個分類的團隊，多個以「、」串接；空白代表所有團隊都能用 |
| 啟用狀態 | 以徽章顯示「啟用」或「停用」，可排序 |
| 更新時間 | 系統自動記錄的最後修改時間，預設由新到舊排序 |
| 操作 | 每列的「修改」與「刪除」，固定在最右側 |

「修改」需要分類清單的修改權限，「刪除」需要刪除權限，沒有權限的按鈕不會出現。刪除前會跳出「確認刪除」視窗：「確定要刪除這筆紀錄嗎？此操作無法復原。」，按「刪除」才會執行。

### 新增／修改對話窗（分類資料）

| 欄位 | 說明 |
|---|---|
| 名稱（必填） | 最長 100 字元，全系統不可重複 |
| 啟用狀態 | 開關，顯示「啟用」或「停用」，新增時預設啟用 |
| 描述 | 多行文字，最長 2000 字元 |
| 適用團隊 | 可複選；提示文字為「選擇可使用此分類的團隊（不設定表示所有團隊皆可使用）」，選項是所有啟用中的團隊 |

對話窗按「儲存」後，會依序經過這些關卡：

1. 欄位檢查，例如名稱空白會顯示「分類名稱 不可為空白」。
2. 修改時若沒有任何變更，顯示「沒有任何變更，未進行儲存。」並關閉視窗。
3. 「確認儲存」視窗，選「儲存」繼續、選「再檢查」回到表單。
4. 名稱重複檢查，重複時顯示「分類名稱已存在，無法新增。」或「分類名稱已存在，無法修改。」。
5. 「確認團隊設定」視窗，視情況出現以下其中一種，選「仍要儲存」繼續、選「回去編輯」回到表單：
   - 適用團隊留空：「此分類未指定適用團隊，將出現在所有使用者的分類下拉清單中（視同公用分類）。確定要這樣儲存嗎？」
   - 你不是管理員、自己有所屬團隊，但選的團隊一個都不包含你：「此分類指定的團隊不包含你所屬的任何團隊，儲存後你將無法在分類清單中看到這筆資料。確定要這樣儲存嗎？」

按「取消」、右上角關閉或 Esc 時，若有未儲存的變更，會問「尚有未儲存的變更」，選「放棄變更」關閉、選「繼續編輯」留下。

> **提醒**：**停用分類不會影響已經掛了它的專案**。停用後它只是不再出現在專案的分類下拉選單與分類過濾器中；既有專案上的分類名稱仍會保留並照常顯示。

> **提醒**：刪除分類時不會檢查是否還有專案在使用，也不會把名稱從既有專案上移除。

## 四、建議這樣操作，會得到什麼

### 情境一：新增一個全公司共用的分類

1. 按「新增」，輸入名稱與描述。
2. 「適用團隊」保持空白，啟用狀態維持「啟用」。
3. 按「儲存」並在「確認儲存」選「儲存」。
4. 在「確認團隊設定」看到公用分類的提醒，確認無誤後選「仍要儲存」。

會得到：所有使用者在專案項目的分類下拉選單都看得到這個分類。

### 情境二：讓某個分類只給特定團隊使用

1. 在該列按「修改」。
2. 在「適用團隊」選擇需要的團隊。若你自己不在這些團隊中，儲存時會提醒你存檔後將看不到它。
3. 儲存並確認。

會得到：只有所選團隊的成員（以及管理員與沒有團隊的使用者）會在下拉選單看到這個分類。

### 情境三：淘汰一個不再使用的分類

1. 在該列按「修改」，把啟用狀態切到「停用」。
2. 儲存並確認。

會得到：新專案選不到這個分類，但已經使用它的舊專案資料不受影響。比起直接刪除，停用保留了日後重新啟用的彈性。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| 分類 | 替專案歸類的標籤，一筆專案可以掛多個分類 |
| 適用團隊 | 可以在下拉選單裡選用這個分類的團隊；留空代表所有團隊都能用 |
| 公用分類 | 適用團隊留空的分類，所有使用者都看得到、選得到 |
| 啟用狀態 | 停用的分類不會出現在專案的下拉選單，但不影響既有專案 |
| 你所屬的團隊 | 使用者管理裡直接替你綁定的團隊，加上你所有角色帶來的預設團隊 |
| 權限 | 角色被允許的動作（新增、修改、刪除），決定你看得到哪些按鈕 |

## 七、常見問題

**為什麼同事看得到的分類，我在這份清單上看不到？**
那個分類只限其他團隊使用，而你不屬於其中任何一個團隊。這份清單和下拉選單套用同一套規則。需要使用時，請管理員調整你的團隊或該分類的適用團隊。

**分類的適用團隊留空，和專案的團隊留空一樣嗎？**
不一樣。分類留空代表所有團隊都能使用這個分類；專案留空代表這筆專案公開給所有人看。兩者都是「最寬鬆」，但一個管的是下拉選單，一個管的是資料可見範圍。

**我把分類停用了，為什麼舊專案上還看得到它？**
停用只會讓它從下拉選單消失，不會修改既有專案。在舊專案的編輯窗中，它會以「（已限定其他團隊）」的標示保留在分類欄位裡，存檔時不會被清掉；若想移除，請在該專案中手動取消選取。
