# 變更密碼

**修改自己的登入密碼**：先輸入目前密碼證明是本人，再設定新密碼。

### 一分鐘看懂這一頁

- **解決什麼問題**：定期更換密碼、懷疑密碼外洩，或管理員給了你一組初始密碼時，讓你自行改成只有自己知道的密碼。
- **誰會用到**：所有使用帳號密碼登入的人；系統預設的開發帳號 `support` 例外，不能在這裡改密碼。
- **它在系統的哪個位置**：不在側邊選單裡。入口是右上角使用者選單的「變更密碼」（開的是對話窗），或直接在網址列輸入這一頁的網址。
- **開始前要準備**：你必須記得**目前的密碼**；另外先想好新密碼，建議至少 6 個字元，並避免使用 `123456`。
- **做完會得到**：新密碼立即生效，下次登入時請改用新密碼；你目前的登入狀態會維持，不需要重新登入。
- **它不做什麼**：不能替別人改密碼，也不能在忘記目前密碼時使用；那兩種情況分別要找管理員或使用登入頁的「忘記密碼？」。

## 一、功能摘要

變更密碼有兩個入口，功能相同，但**檢查規則不完全一樣**：一個是這一頁（網址直接開啟，或被系統強制導來），另一個是右上角使用者選單裡的「變更密碼」對話窗。兩者都要輸入目前密碼、新密碼與確認新密碼，驗證通過後立即更新你的登入密碼。這一頁成功後會回到首頁，對話窗成功後則留在原本的頁面。

## 二、這個頁面在做什麼

系統會先確認你輸入的目前密碼正確，再檢查新密碼與確認新密碼是否一致，全部通過後才把新密碼存起來。

**被系統強制帶到這一頁**：如果你目前的密碼是 `123456`（通常是管理員建立帳號時給的初始密碼），登入後不論點哪一頁，系統都會把你帶回這一頁，直到你改成別的密碼為止。改完後就能正常使用其他頁面。

> **提醒**：這一頁與對話窗都**不會阻止**你把新密碼設成 `123456`。如果你這樣設定，下次換頁時又會被帶回這裡要求變更，請務必改成其他密碼。

變更密碼後，你在這台電腦上的登入狀態會維持；其他裝置上已經登入的畫面也不會因此被登出。若你是因為懷疑密碼外洩而改密碼，請在其他裝置上自行登出。

## 三、畫面上有哪些按鈕、各自做什麼

### 這一頁的欄位與按鈕

標題「變更密碼」下方會顯示你目前登入的帳號，方便確認改的是哪一個帳號。

| 欄位／按鈕 | 說明 |
|---|---|
| 目前密碼（必填） | 提示文字「請輸入目前密碼」；用來確認是本人 |
| 新密碼（必填） | 提示文字「請輸入新密碼」；這一頁**沒有最短長度限制** |
| 確認新密碼（必填） | 提示文字「請再次輸入新密碼」；必須和新密碼完全相同 |
| 儲存 | 送出變更；成功時顯示「密碼已變更。」並回到首頁 |
| 取消 | 不做任何變更，直接回到首頁 |

欄位沒填或兩次新密碼不同時，欄位下方會顯示原因（例如「目前密碼 不可為空白」、「新密碼與確認密碼不一致」），畫面右下角同時跳出「變更密碼失敗」：「請確認密碼欄位皆已正確填寫。」。目前密碼打錯時，右下角會顯示「變更密碼失敗」：「目前密碼不正確。」。

若你登入的是 `support` 帳號，這一頁不會出現表單，只會顯示「系統預設開發帳號 support 禁止變更密碼」。

### 右上角使用者選單的「變更密碼」對話窗

點右上角你的名稱，展開選單後選「變更密碼」，會開啟標題為「變更密碼」的對話窗。欄位同樣是目前密碼、新密碼、確認新密碼，錯誤訊息會以紅色提示框顯示在欄位下方。

| 按鈕 | 做什麼 |
|---|---|
| 確認變更 | 檢查並送出；成功時關閉對話窗並顯示「密碼變更成功！」，留在原本的頁面 |
| 取消 | 關閉對話窗，不做任何變更；下次開啟時欄位會清空 |

若你登入的是 `support` 帳號，對話窗只會顯示「系統預設帳號 support 不允許變更密碼。」。

### 兩個入口的差異

| 項目 | 右上角對話窗 | 這一頁 |
|---|---|---|
| 送出按鈕 | 確認變更 | 儲存（另有「取消」回首頁） |
| 新密碼長度 | **至少 6 個字元**，不足時顯示「新密碼至少需要 6 個字元。」 | **沒有下限** |
| 目前密碼沒填 | 「請輸入目前密碼。」 | 「目前密碼 不可為空白」 |
| 兩次新密碼不同 | 「新密碼與確認密碼不一致。」 | 「新密碼與確認密碼不一致」 |
| 目前密碼打錯 | 「目前密碼輸入錯誤。」 | 「目前密碼不正確。」 |
| 成功後 | 顯示「密碼變更成功！」，留在原頁 | 顯示「密碼已變更。」，回到首頁 |

> **提醒**：建議一律使用至少 6 個字元的新密碼。這一頁雖然允許更短的密碼，但太短的密碼容易被猜中。

## 四、建議這樣操作，會得到什麼

### 情境一：第一次登入，被要求變更初始密碼

1. 登入後系統自動帶你到這一頁。
2. 在「目前密碼」輸入管理員給你的初始密碼。
3. 在「新密碼」與「確認新密碼」輸入同一組新密碼，至少 6 個字元，且不要是 `123456`。
4. 按「儲存」。

會得到：看到「密碼已變更。」後回到首頁，之後可以正常使用各個頁面，下次登入請用新密碼。

### 情境二：工作到一半，想順手換個密碼

1. 點右上角你的名稱，選「變更密碼」。
2. 依序輸入目前密碼、新密碼與確認新密碼。
3. 按「確認變更」。

會得到：看到「密碼變更成功！」，對話窗關閉，你仍停留在原本的頁面，手邊的工作不受影響。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| 目前密碼 | 你現在用來登入的密碼，變更前必須輸入正確才能繼續 |
| 初始密碼 | 管理員建立帳號時給你的密碼；若是 `123456`，系統會要求你先改掉才能使用 |
| 強制變更密碼 | 密碼仍是 `123456` 時，不論點哪一頁都會被帶回變更密碼頁 |
| 使用者選單 | 畫面右上角顯示你名稱的選單，裡面有「變更密碼」、「關於」、「登出」 |
| `support` 帳號 | 系統預設的開發帳號，密碼由系統設定檔決定，不能在這裡變更 |
| 忘記密碼 | 登入頁上的自助重設功能，只有系統啟用寄信時才會出現 |

## 六、相關頁面

以下列出與這一頁搭配使用的頁面；你沒有權限進入的頁面不會顯示。

- [首頁](/App)：這一頁按「儲存」成功或按「取消」後都會回到首頁。
- [使用者管理](/myusers)：忘記目前密碼又無法自助重設時，管理員可以在這裡替你設定新密碼。

## 七、常見問題

**我忘記目前的密碼，怎麼辦？**
這一頁一定要輸入正確的目前密碼。請先登出，在登入頁點「忘記密碼？」自助重設；如果登入頁沒有這個連結，代表系統沒有啟用寄信，請聯絡管理員替你重設。

**為什麼我點任何頁面都會被帶回變更密碼頁？**
因為你的密碼目前是 `123456`，系統要求先改掉才能使用其他功能。改成其他密碼後就會恢復正常。

**同樣的新密碼，為什麼在這一頁可以存、在右上角的對話窗卻被擋？**
右上角對話窗要求新密碼至少 6 個字元，這一頁沒有這個限制。兩邊的檢查規則本來就不完全一樣，建議都使用 6 個字元以上的密碼。

**改完密碼後，其他電腦上的登入會被登出嗎？**
不會。其他裝置上已經登入的畫面會繼續維持登入，若擔心密碼外洩，請到那些裝置上自行登出。
