# 系統參數

在畫面上調整**系統名稱、各種紀錄的保留天數、監控與告警的門檻、流量與忘記密碼的限制**，按儲存後**立即生效，不需要重新啟動網站**。沒有改過的參數沿用伺服器設定檔的值，隨時可以「還原為設定檔值」。

> 這一頁只有管理員可以使用。

### 一分鐘看懂這一頁

- **解決什麼問題**：以前要改保留天數或系統名稱，得請部署人員改伺服器的設定檔（系統名稱還要重新啟動）；現在管理員在這一頁就能改，而且每一次修改都留下稽核紀錄。
- **誰會用到**：負責維運的系統管理員。上線時設定系統名稱與保留天數；之後依法規、磁碟空間或告警頻率調整。
- **它在系統的哪個位置**：左側選單「系統管理 › 系統參數」。改了保留天數之後，清除的動作由「排程作業」頁的各個清理作業執行。
- **開始前要準備**：知道各種紀錄依規定要保留多久（例如稽核紀錄是否有保存年限）、希望多久收到一次例外告警。
- **做完會得到**：新的值馬上生效（各參數的「生效」說明寫了確切時機）；表格的「來源」欄會顯示「系統參數」；稽核紀錄多一筆 `SystemParameter.Update`。
- **它不做什麼**：不能改密碼、金鑰、連線字串、檔案路徑、版本號與排程的執行時間（這些仍在伺服器設定檔）；不能在這裡設定告警的收件人；不會立刻刪除資料（保留天數改短後，由下一次排程清理執行）。

## 一、功能摘要

在這裡可以做什麼：

- 依「系統識別」「資料保留」「監控與告警」「安全與流量」「備份」五類，看每個參數的目前值、設定檔的值、來源與說明。
- 按「修改」輸入新值並儲存，立即生效。
- 按「還原為設定檔值」取消自己的修改，回到伺服器設定檔的值。
- 縮短保留天數時，系統會先跳出紅色的確認窗提醒你資料會被永久刪除。
- 每一次修改與還原都會寫進稽核紀錄（舊值 → 新值）。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 系統管理員（上線設定） | 設定系統名稱與簡介，讓登入頁、側邊欄、PDF 報告與系統寄出的信件顯示正確的名稱。 |
| 系統管理員（依規定調整） | 稽核紀錄有保存年限規定時，把保留天數調長或設為 0（不清除）。 |
| 系統管理員（處理問題） | 磁碟吃緊時縮短保留天數；告警信太多或太少時調整告警門檻；被誤判為大量請求時調整流量上限。 |

### 值從哪裡來

- 每個參數都有一個**設定檔的值**（伺服器的設定檔，由部署人員維護）。
- 你在這一頁修改後，改用**系統參數**的值，蓋過設定檔的值；按「還原為設定檔值」就回到設定檔的值。
- 你改過的值存在系統的資料庫裡，網站重新啟動、或有多台主機時都會套用（其他主機約 1 分鐘內同步）。
- 系統更新後若某個值已經不在允許範圍內，它會標示「未套用」並暫時沿用設定檔的值，請重新修改或還原。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 管理員 | 進入這一頁並使用所有功能。只有帳號勾選了「管理員」的人能進來，這個權限**不在**角色管理的權限表裡，無法透過角色開放。 |

### 它跟其他頁面的分工

| 想做的事 | 去哪裡 |
|---|---|
| 修改保留天數、門檻、系統名稱 | 這一頁 |
| 看清理作業什麼時候跑、立即清一次、修改執行時間 | 「排程作業」（執行時間仍在設定檔） |
| 查誰在什麼時候改了哪個參數 | 「稽核紀錄」 |
| 看已經被清除的是哪些資料 | 「稽核紀錄」「系統例外紀錄」「AI 對話紀錄」「Token 用量」 |

## 四、建議這樣操作，會得到什麼

### 上線時設定系統名稱

1. 在「系統識別」的「系統名稱」按「修改」，輸入正式名稱後儲存。
2. 需要的話也修改「系統簡介」。
3. 換一個頁面或重新整理，側邊欄與「關於」就會顯示新的名稱。

**會得到什麼**：登入頁、側邊欄、瀏覽器分頁、PDF 報告與系統寄出的信件都使用新的名稱，不必請部署人員改設定檔或重新啟動網站。

### 依規定延長稽核紀錄的保存期間

1. 在「資料保留」的「稽核紀錄保留天數」按「修改」。
2. 輸入規定的天數（例如 1825，約 5 年），或輸入 0 表示永遠不自動清除。
3. 儲存。

**會得到什麼**：之後的排程清理只會刪除超過新天數的紀錄；稽核紀錄裡也留下一筆 `SystemParameter.Update`，記錄是誰在何時把天數從多少改成多少。

### 磁碟空間吃緊，想縮短保留天數

1. 先到相關頁面匯出要留存的資料（例如稽核紀錄的 CSV）。
2. 在這一頁把保留天數改短，在紅色確認窗按「確定縮短」。
3. 想馬上清掉，再到「排程作業」對應的清理作業按「立即執行」。

**會得到什麼**：超過新天數的舊資料被永久刪除，磁碟空間釋放；不按「立即執行」的話，會在下一次排程（預設每天 03:00）刪除。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **設定檔的值** | 伺服器設定檔裡的值，由部署人員維護。這一頁沒改過的參數都用它。 |
| **系統參數** | 在這一頁改過的值，存在資料庫裡，會蓋過設定檔的值。 |
| **未套用** | 資料庫裡有改過的值，但它已經不合法（例如系統更新後範圍變了），所以暫時沿用設定檔的值。 |
| **保留天數** | 紀錄保留多久，超過的會由排程作業自動刪除；0 通常表示不自動刪除（各參數的範圍欄有寫）。 |
| **立即生效** | 存檔後不需要重新啟動網站；確切時機見每個參數的「生效」說明（例如保留天數是在下一次排程清理時使用）。 |

## 七、常見問題

**問：改了系統名稱，側邊欄為什麼還是舊的？**
答：已經開著的畫面要換一個頁面或重新整理才會更新；新寄出的信件與新產生的 PDF 會立刻使用新名稱。

**問：保留天數改短了，資料為什麼還沒被刪？**
答：刪除由排程作業執行（預設每天 03:00）。想馬上刪，請到「排程作業」對該清理作業按「立即執行」。

**問：部署人員改了設定檔，為什麼這裡的「目前值」沒變？**
答：這個參數在這一頁被改過，系統參數會蓋過設定檔的值。要改用設定檔的值，請按「還原為設定檔值」。

**問：為什麼找不到密碼、金鑰或告警收件人？**
答：機密資料、檔案路徑、版本號、排程執行時間與告警收件人這類值刻意不放在畫面上，仍由部署人員在伺服器設定檔維護。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、要修改的參數與輸入的值、畫面或窗內的訊息（最好截圖），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
