# 專案項目

建立與追蹤專案：記錄進度、狀態與負責人，**掛上分類與團隊標籤**，並**上傳附件**。

### 一分鐘看懂這一頁

- **解決什麼問題**：把專案的排程、進度、負責人與相關檔案集中在一張清單裡管理，並用團隊標籤控制誰看得到哪一筆。
- **誰會用到**：負責建立與更新專案的同仁，以及需要查詢專案進度的主管；能做哪些動作依你角色的權限而定。
- **它在系統的哪個位置**：側邊選單「專案管理」群組底下；它使用「資料定義」群組裡維護的分類與團隊當作下拉選項。
- **開始前要準備**：先確認需要的分類與團隊已經在分類清單、團隊清單建好並啟用，否則下拉選單裡選不到。
- **做完會得到**：一筆有標題、負責人、狀態、進度、分類、團隊與附件的專案紀錄，只有看得到它的人會在清單上看到。
- **它不做什麼**：不會通知負責人、不會連動使用者帳號，也不負責維護分類或團隊本身（那是分類清單與團隊清單的工作）。

## 一、功能摘要

這一頁以清單呈現你看得到的專案，每頁 8 筆，預設依標題由小到大排序。你可以新增、修改、刪除專案（依權限顯示），用關鍵字搜尋，或用分類、團隊過濾清單。每一筆專案可以掛多個分類與多個團隊，並上傳多個附件。這是系統內建的示範業務模組，瀏覽器分頁上顯示的標題是「專案管理」。

## 二、這個頁面在做什麼

清單只會出現你**看得到**的專案。可見規則由專案上的「團隊」決定：

- 團隊欄位**留空**的專案是**公開的**，所有能進這一頁的人都看得到。
- 有指定團隊的專案，只有屬於其中任一團隊的人看得到。你所屬的團隊，是使用者管理裡直接替你綁定的團隊，加上你所有角色帶來的預設團隊。
- 管理員看得到全部專案。

團隊是用**團隊名稱**比對的。團隊改名後，專案上記的仍是舊名稱，不會自動更新，可見範圍可能因此出錯；團隊被停用後，已經屬於它的人仍然看得到它的專案。

能不能新增、修改、刪除，則是由角色權限決定，和團隊是兩回事：看得到一筆專案，不代表可以修改它。

## 三、畫面上有哪些按鈕、各自做什麼

### 工具列

| 按鈕／欄位 | 做什麼 | 何時出現 |
|---|---|---|
| 「新增」 | 開啟「新增專案」對話窗 | 有專案項目的新增權限才出現 |
| 「重新整理」 | 重新讀取清單，並顯示「已更新最新資料」 | 一律出現 |
| 「分類過濾」 | 可複選；只列出有掛任一所選分類的專案 | 一律出現 |
| 「團隊過濾」 | 可複選；只列出有掛任一所選團隊的專案 | 一律出現 |
| 「請輸入搜尋關鍵字」 | 輸入關鍵字後按「搜尋」 | 一律出現 |
| 「清空搜尋」 | 清掉關鍵字並回到第一頁 | 搜尋框有文字時才出現 |
| 「搜尋」 | 依關鍵字重新查詢並回到第一頁 | 一律出現 |

> **提醒**：關鍵字只比對標題、描述、狀態、優先級、負責人，**不會比對分類與團隊**；要依分類或團隊找資料，請改用兩個過濾器。

> **提醒**：「團隊過濾」列出的是所有啟用中的團隊，不只你所屬的；選了你不屬於的團隊，清單仍只會顯示你看得到的專案（通常是空的）。

### 清單欄位

| 欄位 | 意思 |
|---|---|
| 標題 | 專案名稱，可排序 |
| 描述 | 補充說明 |
| 開始日期／結束日期 | 預計或實際的起訖日，可排序 |
| 狀態 | 以徽章顯示：已完成為綠色，進行中為強調色，暫緩為橘色，未開始與等待為灰色 |
| 優先級 | 低、中、高 |
| 完成百分比 | 0 到 100 的整數 |
| 負責人 | 負責人的名稱（純文字） |
| 分類／團隊 | 多個值以「、」串接顯示 |
| 建立時間／更新時間 | 系統自動記錄，任何畫面都不能修改 |
| 操作 | 每列的「修改」與「刪除」，固定在最右側，左右捲動時不會跑掉 |

「修改」需要專案項目的修改權限，「刪除」需要刪除權限，沒有權限的按鈕不會出現。刪除前會跳出「確認刪除」視窗，內容為「確定要刪除這筆紀錄嗎？此操作無法復原。」，按「刪除」才會執行；**該專案的附件實體檔案也會一起刪除**。

### 新增／修改對話窗

| 區塊 | 欄位 | 說明 |
|---|---|---|
| 基本資料 | 標題（必填） | 專案名稱 |
| | 負責人（必填） | **純文字名稱，不是系統帳號**，不會和使用者管理連動，打錯字也不會有人提醒 |
| | 描述 | 多行文字 |
| 排程與進度 | 開始日期、結束日期 | 選填；結束日期不可早於開始日期 |
| | 狀態（必填） | 未開始、進行中、已完成、暫緩、等待，新增時預設「未開始」 |
| | 優先級（必填） | 低、中、高，新增時預設「中」 |
| | 完成百分比（必填） | 0 到 100，新增時預設 0 |
| 分類與團隊 | 分類 | 可複選；只列出你所屬團隊可以使用、且啟用中的分類 |
| | 團隊 | 可複選；提示文字為「選擇團隊（不設定表示公開）」 |
| 專案附件 | 新增附件 | 可一次選多個檔案，每個檔案上限 1GB |
| | 待上傳檔案 | 這次選好、但還沒儲存的檔案，可按「移除」撤回 |
| | 已上傳檔案 | 先前存好的附件，點檔名可下載；按「移除」會在儲存時刪除 |

> **提醒**：**團隊留空＝公開給所有人看**，不是「沒有人看得到」。儲存時系統會先問「確認儲存」，團隊留空時再跳出「確認團隊設定」視窗：「此專案未指定團隊，將對所有使用者公開可見。確定要這樣儲存嗎？」，選「仍要儲存」才會存成公開，選「回去編輯」可以補上團隊。

> **提醒**：新增專案時，團隊欄位會預先帶入你目前所屬、而且仍啟用中的團隊。若你沒有任何團隊（例如沒有綁團隊的管理員），這一欄會是空白，存檔時就會變成公開專案。

> **提醒**：若這筆專案原本掛了目前下拉選單裡沒有的分類，選單會多出一個標示「（已限定其他團隊）」的選項，保留原值，避免你存檔時不小心把它清掉。除了限定其他團隊的分類，已停用或已刪除的分類也會以這個標示出現。

> **提醒**：附件超過 1GB，選檔當下就會顯示「〈檔名〉 超過 1GB 限制」並略過該檔。檔案類型則在**按儲存時**才檢查，不在允許清單內會顯示「檔案 〈檔名〉 的類型不在允許清單中。」，請把它從待上傳檔案移除後再儲存。預設允許常見的文件、試算表、簡報、圖片與壓縮檔（例如 PDF、Word、Excel、PowerPoint、純文字、CSV、JPG、PNG、ZIP），網頁檔與執行檔會被擋下；實際清單以系統管理員的設定為準。

對話窗底部的按鈕：

| 按鈕 | 做什麼 |
|---|---|
| 儲存 | 檢查欄位後跳出「確認儲存」視窗，選「儲存」才會寫入並上傳附件；選「再檢查」回到表單。修改時若沒有任何變更，會顯示「沒有任何變更，未進行儲存。」並關閉視窗 |
| 取消（或右上角關閉、按 Esc） | 有未儲存的變更時，會問「尚有未儲存的變更」，選「放棄變更」關閉、選「繼續編輯」留下；**待上傳的檔案也算變更，取消後會一起丟掉** |

## 四、建議這樣操作，會得到什麼

### 情境一：建立一個只給自己團隊看的專案

1. 按工具列的「新增」。
2. 填寫標題、負責人，視需要調整狀態、優先級與完成百分比。
3. 在「分類」選擇適用的分類，確認「團隊」已帶入你的團隊；不夠的話再補選。
4. 在「新增附件」選擇相關檔案，確認它們出現在待上傳檔案中。
5. 按「儲存」，在「確認儲存」視窗選「儲存」。

會得到：清單上多出這筆專案，附件已上傳，只有所選團隊的成員與管理員看得到它。

### 情境二：找出某個分類下仍在進行中的專案

1. 在「分類過濾」選擇該分類。
2. 在搜尋框輸入「進行中」，按「搜尋」。
3. 需要的話點「更新時間」欄標題排序。

會得到：只剩該分類中狀態為進行中的專案，方便追蹤進度。

### 情境三：更新進度並替換附件

1. 在該列按「修改」。
2. 調整完成百分比與狀態。
3. 在已上傳檔案中，對舊版檔案按「移除」；再到新增附件選擇新版檔案。
4. 按「儲存」並確認。

會得到：專案進度更新，舊附件被刪除，新附件完成上傳。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| 公開專案 | 團隊欄位留空的專案，所有能進入這一頁的人都看得到 |
| 團隊 | 決定誰看得到這筆專案的標籤；以團隊名稱比對，團隊改名後舊專案不會自動跟著改 |
| 你所屬的團隊 | 使用者管理裡直接替你綁定的團隊，加上你所有角色帶來的預設團隊 |
| 分類 | 替專案歸類的標籤，由分類清單維護，只能選你所屬團隊可以使用的分類 |
| 負責人 | 一段純文字名稱，不對應任何系統帳號 |
| 待上傳檔案 | 已選好但尚未儲存的附件，按「取消」會一起丟掉 |
| 權限 | 角色被允許的動作（新增、修改、刪除），決定你看得到哪些按鈕 |

## 七、常見問題

**我明明存了一筆專案，存完卻在清單上找不到？**
最常見的原因是你把團隊改成自己不屬於的團隊，存檔後你就看不到它了，系統不會事先提醒。另外也請確認分類、團隊過濾器與搜尋框是否還留著條件。需要找回時，請屬於該團隊的同仁或管理員協助。

**團隊欄位留空，是不是就沒有人看得到？**
正好相反。團隊留空的專案是公開的，所有能進入這一頁的人都看得到。要限制可見範圍，請至少指定一個團隊。

**負責人打錯字或那個人離職了，系統會提醒嗎？**
不會。負責人只是一段文字，不會和系統帳號比對，請自行修改。

**附件選了卻沒有出現在待上傳檔案裡？**
超過 1GB 的檔案在選檔時就被略過，畫面右下角會顯示超過限制的訊息。若檔案有出現在清單、但按儲存後失敗，通常是檔案類型不在允許清單中，請移除後再儲存。
