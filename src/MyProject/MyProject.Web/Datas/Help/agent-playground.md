# Agent 測試台

和一個**會使用工具的 AI 助理（Agent）**對話：範例「專案小幫手」會幫你搜尋專案，也能在**你核准後**修改專案描述。它示範 Agent 怎麼依你的權限做事、怎麼在改資料前先問你。

### 一分鐘看懂這一頁

- **解決什麼問題**：想知道 AI 助理「能做到什麼、會不會亂改資料」。這一頁讓你實際問問看，並親眼看到它要改資料時會先跳出核准窗。
- **誰會用到**：管理員授權了「Agent 測試台」的人（管理員一律可以用），通常是要評估 AI 助理、或日後開發新 Agent 的人。
- **它在系統的哪個位置**：左側選單「AI 助理 › Agent 測試台」。
- **開始前要準備**：系統要先設定好 AI（未設定時頁面會顯示原因）。想試修改功能，你要有「專案項目」的編輯權限。
- **做完會得到**：AI 依你看得到的專案回答問題；你核准後，專案描述真的被修改並留下稽核紀錄。
- **它不做什麼**：不讓別人看到你的對話（連管理員在這一頁也看不到）；不能做你權限以外的事；除了搜尋專案與修改描述，不會做其他操作。對話不會永久保存，最後一次對話超過保存天數會自動刪除。

## 一、功能摘要

- 用一般說話的方式請 AI 助理查專案，例如「列出狀態是進行中的專案」。
- 請它修改專案描述時，會先跳出核准窗，列出要改哪一筆、改成什麼；你按「核准」才會真的修改。
- 回覆會一段段出現，可以隨時按「停止產生」。
- 對話會自動保存在左側「我的對話」，之後點一下就能接著聊，AI 記得先前說過的內容。
- 「新對話」開始一段新的對話，原本的對話仍留在「我的對話」。
- 沒有專案資料可以試？按「產生 10 筆測試專案」，系統會建立 10 筆繁體中文的測試專案，並跳出說明告訴你可以怎麼問；用完按「清除測試專案」永久刪除。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 使用者 | 為什麼來這一頁 |
|---|---|
| 管理員 | 評估 AI 助理的能力與安全性，決定要不要開放給其他角色。 |
| 被授權的使用者 | 試用 AI 助理查專案、整理專案描述。 |
| 開發人員 | 看一個完整的 Agent 範例（工具、權限、核准、記帳），作為開發新 Agent 的參考。 |

### AI 助理怎麼做事

- 它有兩個「工具」：**搜尋專案**（需要「專案項目」的檢視權限）與**修改專案描述**（需要「專案項目」的編輯權限）。
- 工具一律以**你的身分**執行：你看不到的專案（例如不在你團隊範圍內的），它也看不到、改不了。
- **修改專案描述一定會先問你**。如果你根本沒有編輯權限，不會跳出核准窗，AI 會直接告訴你沒有權限。
- 每一次 AI 呼叫都記在「Token 用量」（作業名稱「Agent 測試台」）與「AI 對話紀錄」。AI 一次回覆可能呼叫好幾次模型（先查資料再回答），每次各記一筆、共用同一個執行編號。
- 工具的執行、被權限擋下、被你拒絕，都會記在「稽核紀錄」（`Ai.ToolInvoked`、`Ai.ToolDenied`、`Ai.ToolRejected`），只記工具名稱與結果，不記內容。

### 對話怎麼保存

- 送出第一則訊息後，這段對話就會出現在左側「我的對話」；之後每次 AI 回覆完、你按「停止產生」、發生錯誤、停下來等你核准，或你離開頁面時，都會自動存起來。只按「新對話」而沒有送出訊息，不會多出空白的對話。
- **只有你自己看得到、刪得掉**，別人（包括管理員）在這一頁看不到你的對話。管理員仍可在「AI 對話紀錄」看到每一次實際送給 AI 的內容。
- 最後一次對話超過保存天數（頁面上方的說明會寫幾天，管理員在「系統參數」的「資料保留」設定，預設 90 天）就會自動刪除。
- 接著聊時，AI 使用**目前**設定的模型（可能和上次不同），也會使用目前的 AI 提示詞。

### 需要的權限

| 角色 | 可以做什麼 |
|---|---|
| 管理員 | 一律可以進入與使用，也一律有專案權限。 |
| 被授權「Agent 測試台」的角色 | 可以進入與對話；AI 能不能查或改專案，取決於這個角色有沒有「專案項目」的檢視／編輯權限。有「專案項目」的新增權限才看得到「產生 10 筆測試專案」，有刪除權限才看得到「清除測試專案」。 |
| 其他人 | 看不到選單，直接開網址會顯示「你沒有權限存取此頁面」。 |

### 它跟其他頁面的分工

| 你想做的事 | 去哪一頁 |
|---|---|
| 跟 AI 助理對話、試用工具 | 這一頁 |
| 讓多個 AI 助理依流程完成一件事（寫專案狀態報告、多觀點審查） | 「Agent 工作流程」 |
| 直接查詢或修改專案 | 「專案項目」 |
| 看 AI 每一次實際送出與收到的內容 | 「AI 對話紀錄」（管理員） |
| 看 AI 花了多少 token 與費用 | 「Token 用量」（管理員） |
| 調整 AI 助理的指示 | 「AI 提示詞」的「Agent 測試台」分頁（管理員） |
| 換 AI 助理使用的模型或推論等級 | 「系統參數」的「AI 模型」（管理員） |

## 四、建議這樣操作，會得到什麼

### 用測試專案試試看

1. 按右上角「產生 10 筆測試專案」，看完說明窗後關閉。
2. 在輸入框貼上「哪些測試專案的狀態是『進行中』？各自的風險是什麼？」，按「送出」。
3. AI 會搜尋測試專案並整理每一筆的風險。試完按「清除測試專案」，確認後全部永久刪除。

### 查專案

1. 在輸入框打「列出所有專案」，按「送出」。
2. 對話區出現「🔧 呼叫工具：搜尋專案」，接著出現 AI 的整理。
3. 只會列出你看得到的專案（和「專案項目」頁相同）。

### 請它修改專案描述

1. 打「把專案 3 的描述改成『已結案，等待驗收』」，按「送出」。
2. AI 先搜尋確認是哪一筆，接著跳出核准窗，列出專案 Id 與新描述。
3. 確認無誤按「核准」；AI 回覆已修改。到「專案項目」頁可以看到新的描述。

### 確認權限真的有效

1. 請管理員建立一個只有「Agent 測試台」與「專案項目」檢視權限（沒有編輯）的角色，用這個角色登入。
2. 請 AI 修改某個專案描述：不會跳出核准窗，AI 會說你沒有權限；稽核紀錄出現 `Ai.ToolDenied`。

### 接著昨天的對話聊

1. 在左側「我的對話」點那段對話，對話區會還原先前的內容。
2. 直接輸入「剛才那幾個專案，哪個最晚建立？」，AI 會記得先前查到的結果。
3. 如果那段對話標示「待核准」，點開後會重新跳出核准窗；核准時系統仍會再檢查一次你**現在**的權限。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **Agent（AI 助理）** | 除了回答問題，還能自己決定使用工具（查資料、改資料）來完成你的要求的 AI。 |
| **工具** | Agent 可以使用的系統功能，例如「搜尋專案」。每個工具都要求特定權限。 |
| **核准** | 會修改資料的工具在執行前，先讓你確認的步驟。 |
| **執行編號** | AI 一次回覆可能呼叫模型好幾次，這幾次在「AI 對話紀錄」與「Token 用量」共用同一個編號。 |
| **我的對話** | 你在這一頁保存的對話清單，只有你看得到。接續的對話在「AI 對話紀錄」仍屬同一段對話。 |

## 七、常見問題

**問：對話會被保存嗎？會保存多久？**
答：會。送出第一則訊息後自動保存在左側「我的對話」，最後一次對話超過保存天數（頁面上方的說明會寫幾天）自動刪除。不想留可以自己按「刪除這段對話」。

**問：別人看得到我的對話嗎？**
答：在這一頁看不到，連管理員也一樣。但每一次實際送給 AI 的內容會記在「AI 對話紀錄」，管理員可以查看；請不要在對話中輸入密碼等機密。

**問：測試專案會被別人看到嗎？可以重複產生嗎？**
答：測試專案沒有指定團隊，看得到專案的人都看得到，用完請按「清除測試專案」。已經有測試專案時不能再產生，避免同名專案讓 AI 搞混；先清除再產生即可。

**問：點開舊對話時說「這段對話無法接續」？**
答：對話內容已不存在（例如系統從沒有包含 Agent 對話的備份還原）或格式不相容。請刪除它，開一段新對話。

**問：舊對話停在核准窗，我的權限已經被拿掉了，核准會怎樣？**
答：核准後真正執行前，系統會用你**現在**的權限再檢查一次；沒有權限就不會修改，AI 會告訴你沒有權限。

**問：AI 說找不到某個專案，但我在別的地方看過它？**
答：AI 用你的身分搜尋，只看得到你團隊範圍內的專案；也可能是關鍵字不符，換個說法再試。

**問：我核准之後可以反悔嗎？**
答：核准後就會立刻修改。要改回來請到「專案項目」頁手動修改；修改前後的內容都記在稽核紀錄（`Project.Update`）。

**問：為什麼一次回覆在「Token 用量」出現好幾筆？**
