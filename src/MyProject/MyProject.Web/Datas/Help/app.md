# 首頁

登入後預設看到的畫面，讓你**認識這套系統能做什麼**，並從**快速入口**直接前往常用的業務頁面。最底部的**系統版本**與**執行環境**是回報問題時最有用的資訊。

> 首頁只做介紹與導覽，不會讀寫任何業務資料；每個人看到的介紹內容都一樣，只有「快速入口」會依權限不同。

### 一分鐘看懂這一頁

- **解決什麼問題**：剛登入時不知道系統有哪些功能、該從哪裡開始，這一頁用介紹卡片與快速入口替你整理好。
- **誰會用到**：所有登入系統的人；登入成功後預設就會來到這裡，也可以隨時點左側選單的「首頁」回來。
- **它在系統的哪個位置**：左側選單最上方的「首頁」；變更密碼頁按「儲存」成功或按「取消」後，也會回到這裡。
- **開始前要準備**：不需要準備任何資料，只要已經登入；快速入口會依你角色的權限自動決定要顯示哪幾個連結。
- **做完會得到**：知道系統的主要能力，並能一鍵進入你有權限的「專案項目」「分類清單」或「團隊清單」頁面。
- **它不做什麼**：不能在這裡新增或修改任何資料，也不會顯示統計數字、待辦事項或通知；介紹卡片不能點擊。

## 一、功能摘要

在這裡可以做什麼：

- 看系統名稱與系統描述，了解這套系統的用途。
- 讀「系統能力」六張介紹卡片，了解系統的整體範圍。
- 從「快速入口」一鍵前往「專案項目」「分類清單」「團隊清單」（只列出你有權限進入的頁面）。
- 查看「系統版本」與「執行環境」，回報問題時一併提供。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 第一次登入的同事 | 先認識系統有哪些功能，看快速入口就知道自己能進哪些業務頁面。 |
| 日常使用者 | 登入後從快速入口直接進入常用頁面，不必展開左側選單。 |
| 回報問題的人 | 從最底部抄下系統版本與執行環境，交給系統管理員。 |

### 畫面上的內容從哪裡來

- **系統名稱與系統描述**：由系統管理員在系統設定中決定，換一套部署就可能不同。
- **系統能力**：六張固定的文字介紹，分別是「權限與角色控管」「專案項目管理」「分類與團隊定義」「日誌檢視與 AI 分析」「健康監控與資料庫用量」「檔案上傳與保管」。其中「日誌檢視與 AI 分析」與「健康監控與資料庫用量」介紹的是管理員專用功能，一般使用者在左側選單看不到它們是正常的。
- **快速入口**：逐一檢查你是否有該頁面的檢視權限，只顯示你進得去的連結；三個都沒有權限時，整個「快速入口」標題與區塊都不會出現。管理員不受權限限制，三個連結一律顯示。
- **系統版本與執行環境**：系統版本是目前的版本號與發布日期；執行環境顯示 `Development` 代表開發或測試用環境，顯示 `Production` 代表正式環境。

> 「權限與角色控管」卡片的文字提到「檢視／新增／修改／刪除／匯出」，但目前角色權限只有「檢視、新增、編輯、刪除」四種，角色管理畫面裡找不到「匯出」是正常的。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 首頁 | 進入這一頁、看到全部介紹內容。沒有這個權限時，畫面只會顯示「你沒有權限存取此頁面」，左側選單也看不到「首頁」。 |
| 專案項目的檢視 | 快速入口出現「專案項目」連結。 |
| 分類清單的檢視 | 快速入口出現「分類清單」連結。 |
| 團隊清單的檢視 | 快速入口出現「團隊清單」連結。 |

> 權限在「角色管理」的權限設定裡勾選；管理員看得到全部。

## 三、畫面上有哪些按鈕、各自做什麼

首頁沒有表單，由上而下分成四個區塊。

### 畫面區塊

| 欄位 | 意思 | 範例 | 怎麼填或怎麼用 |
|---|---|---|---|
| 系統介紹 | 品牌圖示、「Welcome」字樣、系統名稱與系統描述。 | 「企業管理平台」 | 純顯示，不可操作。 |
| 系統能力 | 六張介紹卡片，每張有圖示、標題與一段說明。 | 「專案項目管理」 | 純文字介紹，**不能點擊**，也不會帶你到對應頁面。 |
| 快速入口 | 最多三個連結。 | 「專案項目」「分類清單」「團隊清單」 | 點一下即前往該頁；只列出你有檢視權限的頁面。 |
| 系統版本 | 目前的版本號與發布日期。 | `1.2.3 (2026/01/15)` | 回報問題時請一併提供。 |
| 執行環境 | 系統目前跑在哪一種環境。 | `Production` | `Development` 是開發或測試環境，`Production` 是正式環境。 |

### 快速入口

### 你可能看到的訊息

| 訊息 | 原因與處理 |
|---|---|
| 你沒有權限存取此頁面 | 你的角色沒有「首頁」權限。請洽系統管理員在角色管理中勾選「首頁」。 |
| 「快速入口」整個區塊不見 | 你對「專案項目」「分類清單」「團隊清單」三頁都沒有檢視權限，這是正常的顯示方式。 |

### 右下角的處理進度提示

這個畫面沒有任何長時間處理的工作，也不會跳出右下角提示。

## 四、建議這樣操作，會得到什麼

### 第一次登入，想知道自己能做什麼

1. 登入後停在首頁，先讀「系統能力」六張卡片，了解系統的整體範圍。
2. 看「快速入口」出現了哪幾個連結，這就是你目前角色能進入的業務頁面。
3. 對照左側選單，確認看得到的項目與快速入口一致。

**會得到什麼**：清楚知道自己的權限範圍；若缺少工作需要的頁面，可以直接請系統管理員調整角色。

> 王小明第一次登入，首頁的快速入口只出現「專案項目」。他本來以為還要自己建分類，看了快速入口才知道分類由別人維護，於是直接點「專案項目」開始建立「官網改版」。

### 回報系統問題

1. 回到首頁，捲到最底部。
2. 抄下「系統版本」與「執行環境」兩項。
3. 連同發生問題的頁面、操作步驟與時間一起交給系統管理員。

**會得到什麼**：系統管理員能立刻判斷你用的是哪一版、哪一個環境，縮短查問題的時間。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **快速入口** | 首頁上直接前往常用業務頁面的連結，只會列出你有權限進入的頁面。 |
| **系統能力** | 六張介紹系統功能的卡片，純說明用，不能點擊。 |
| **系統版本** | 目前系統的版本號與發布日期，回報問題時請一併附上。 |
| **執行環境** | 系統目前跑在開發（`Development`）還是正式（`Production`）環境；兩邊的資料互不相通。 |
| **檢視權限** | 角色被允許進入某個頁面的權限；沒有這個權限，選單與快速入口都不會出現該頁。 |
| **管理員** | 帳號上被設定為管理員的人，可以使用所有功能，不受角色權限限制。 |
| **通知鈴鐺** | 右上角的鈴鐺：系統自動發給你的通知，點一則會標為已讀並帶你到相關頁面；「全部標為已讀」清掉紅色數字。 |
| **公告橫幅** | 管理員發布的公告，在起訖時間內顯示在每個頁面的上方；按「知道了」只對你自己關閉。 |

## 七、常見問題

**問：為什麼我的快速入口少了幾個連結，甚至整段不見？**
答：快速入口只顯示你有檢視權限的頁面，三個都沒有權限時整個區塊會隱藏。需要使用哪一頁，請系統管理員替你的角色加上該頁的檢視權限。

**問：點「系統能力」的卡片為什麼沒有反應？**
答：這六張卡片只是功能介紹，本來就不能點擊。要前往某個功能，請使用左側選單或「快速入口」。

**問：首頁顯示「你沒有權限存取此頁面」是怎麼回事？**
答：首頁本身也是一項可以授予的權限。你的角色沒有「首頁」權限時就會看到這段紅色提示，請系統管理員在角色管理中勾選「首頁」。

**問：卡片提到「日誌檢視」「健康監控」，為什麼我的選單裡找不到？**
答：那兩張卡片介紹的是管理員專用功能，一般使用者看不到是正常的。

**問：登入後為什麼沒有停在首頁，而是直接到了別的頁面？**
答：如果你是先打開某一頁、被要求登入，登入成功後系統會帶你回到原本要去的那一頁；直接開登入頁登入時，才會預設來到首頁。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
