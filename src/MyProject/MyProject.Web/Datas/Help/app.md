# 首頁

登入後預設看到的畫面：上方是**系統名稱與版本**、**快速入口**，下方的**儀表板**一眼看到你的通知、帳號狀態，管理員另外看得到排程作業有沒有異常。

> 儀表板的每個區塊只顯示你自己的資料，看不到別人的；你沒有權限的區塊不會出現。

### 一分鐘看懂這一頁

- **解決什麼問題**：登入後要知道「有沒有新通知、帳號安不安全、系統背景工作有沒有出問題」，不必一頁一頁打開去看。
- **誰會用到**：所有登入系統的人；登入成功後預設就會來到這裡，也可以隨時點左側選單的「首頁」回來。
- **它在系統的哪個位置**：左側選單最上方的「首頁」；變更密碼頁按「儲存」成功或按「取消」後，也會回到這裡。
- **開始前要準備**：不需要準備任何資料，只要已經登入；快速入口與儀表板區塊會依你的權限自動決定要顯示哪些。
- **做完會得到**：看到未讀通知、上一次登入的時間、密碼何時到期與兩步驟驗證狀態；管理員還會看到有問題的排程作業；並能一鍵進入常用頁面。
- **它不做什麼**：不能在這裡新增或修改業務資料；儀表板區塊不能自己拖拉排版或隱藏。

## 一、功能摘要

在這裡可以做什麼：

- 看系統名稱、系統描述、系統版本與執行環境（回報問題時一併提供）。
- 從「快速入口」一鍵前往「專案項目」「分類清單」「團隊清單」（只列出你有權限進入的頁面）。
- 「我的通知」：未讀數與最新 5 則，新通知來時自動更新。
- 「我的帳號」：上一次登入的時間與方式、密碼到期日、兩步驟驗證是否啟用。
- 「排程作業」（只有管理員）：上次執行失敗或中斷、逾期未執行、已停用的作業。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 所有同事 | 登入後先看有沒有新通知、帳號有沒有異常（例如不是自己做的登入）。 |
| 日常使用者 | 從快速入口直接進入常用頁面，不必展開左側選單。 |
| 系統管理員 | 一眼確認背景排程作業（清理、備份、提醒）都正常。 |
| 回報問題的人 | 從最上方抄下系統版本與執行環境，交給系統管理員。 |

### 畫面上的內容從哪裡來

- **系統名稱與系統描述**：由系統管理員在「系統參數」設定。
- **快速入口**：逐一檢查你是否有該頁面的檢視權限，只顯示你進得去的連結；三個都沒有權限時，整個區塊不會出現。管理員一律顯示。
- **我的通知**：和右上角鈴鐺是同一份通知，這裡只列最新 5 則；全部通知與「全部標為已讀」在鈴鐺。
- **我的帳號**：「上一次登入」是倒數第二次成功登入（最近一次通常就是你現在這次）；密碼到期與兩步驟驗證取自你的帳號設定，用 Google 登入、沒有系統密碼的人不顯示這兩項。
- **排程作業**：和「排程作業」頁讀同一份資料；沒有異常時顯示「正常」。
- **系統版本與執行環境**：`Development` 代表開發或測試用環境，`Production` 代表正式環境。

### 某個區塊壞掉時

每個儀表板區塊各自獨立：其中一個讀取失敗，那一塊會顯示「這個區塊暫時無法顯示，其他區塊不受影響（錯誤追蹤碼：…）」，其他區塊照常顯示。把追蹤碼告訴系統管理員即可查到原因。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 首頁 | 進入這一頁。沒有這個權限時，畫面只會顯示「你沒有權限存取此頁面」，左側選單也看不到「首頁」。 |
| 專案項目／分類清單／團隊清單的檢視 | 快速入口出現對應的連結。 |
| 不需要特別權限 | 「我的通知」「我的帳號」兩個區塊，每個人都看得到自己的。 |
| 管理員 | 「排程作業」區塊。 |

> 權限在「角色管理」的權限設定裡勾選；管理員看得到全部。

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 一眼看通知、帳號狀態、排程作業；找常用頁面；查系統版本 | 這一頁 |
| 看全部通知、全部標為已讀 | 右上角的鈴鐺 |
| 看完整的登入紀錄、修改姓名、設定兩步驟驗證 | 右上角使用者選單的「個人資料」 |
| 看排程作業的執行紀錄、立即執行、停用 | 「排程作業」（管理員） |
| 修改自己的登入密碼 | 右上角使用者選單的「變更密碼」 |
| 看系統公告 | 每個頁面上方的公告橫幅 |

## 三、畫面上有哪些按鈕、各自做什麼

首頁沒有表單，由上而下分成三個區塊。

### 畫面區塊

| 欄位 | 意思 | 範例 | 怎麼填或怎麼用 |
|---|---|---|---|
| 歡迎列 | 品牌圖示、「Welcome」字樣、系統名稱、系統描述，以及「系統版本 … · 執行環境 …」。 | 「系統版本 0.9.106 (2026/10/04) · 執行環境 Production」 | 純顯示。回報問題時請一併提供版本。 |
| 快速入口 | 最多三個連結。 | 「專案項目」「分類清單」「團隊清單」 | 點一下即前往該頁。 |
| 儀表板 | 一張張區塊卡片。 | 「我的通知」「我的帳號」「排程作業」 | 見下方各區塊說明。 |

### 儀表板區塊

| 區塊 | 顯示什麼 | 範例 | 注意事項 |
|---|---|---|---|
| 我的通知 | 未讀數字與最新 5 則（未讀的是粗體），每則有時間；有連結的可以點，點了會標為已讀並前往。 | 「3 則未讀」 | 新通知來時不必重新整理就會更新。沒有通知時顯示「沒有通知。」。 |
| 我的帳號 | 上一次登入（時間與「帳號密碼」或「Google 登入」）、密碼到期（快到期時加一個「快到期」標籤）、兩步驟驗證「已啟用／未啟用」。 | 「上一次登入 2026-10-03 09:12 帳號密碼」 | 「前往個人資料」看完整紀錄。看到不是你做的登入，請立即變更密碼並通知系統管理員。 |
| 排程作業 | 有異常的作業與原因（「上次執行失敗」「上次執行被中斷」「逾期未執行」「已停用」）；都正常時顯示「正常」。 | 「系統備份　上次執行失敗」 | 只有管理員看得到。「前往排程作業」看細節或立即執行。總開關關閉時另外提醒。 |

### 快速入口

| 按鈕 | 按下後會做什麼 | 右下角會看到的提示 | 注意事項 |
|---|---|---|---|
| 專案項目 | 前往「專案項目」清單。 | 無 | 你的角色有「專案項目」的檢視權限才會出現。 |
| 分類清單 | 前往「分類清單」。 | 無 | 你的角色有「分類清單」的檢視權限才會出現。 |
| 團隊清單 | 前往「團隊清單」。 | 無 | 你的角色有「團隊清單」的檢視權限才會出現。 |
| 前往個人資料／前往排程作業 | 前往對應頁面。 | 無 | 在「我的帳號」「排程作業」區塊的下方。 |

### 你可能看到的訊息

| 訊息 | 原因與處理 |
|---|---|
| 你沒有權限存取此頁面 | 你的角色沒有「首頁」權限。請洽系統管理員在角色管理中勾選「首頁」。 |
| 這個區塊暫時無法顯示，其他區塊不受影響（錯誤追蹤碼：…） | 那個區塊讀取時出錯；重新整理頁面，仍然發生時把追蹤碼告訴系統管理員。 |
| 排程總開關已關閉，所有作業都不會依排程執行。 | 部署人員在設定檔關閉了排程；確認是否刻意的。 |

### 右下角的處理進度提示

這個畫面沒有任何長時間處理的工作，也不會跳出右下角提示。

## 四、建議這樣操作，會得到什麼

### 每天登入後先看一眼

1. 登入後停在首頁，看「我的通知」有沒有未讀。
2. 看「我的帳號」的「上一次登入」是不是你自己。
3. 管理員再看「排程作業」是否顯示「正常」。

**會得到什麼**：不必打開別的頁面就知道有沒有要處理的事；帳號被別人用過時能及早發現。

> 王小明登入後，「我的帳號」顯示上一次登入是凌晨 3 點的「帳號密碼」，但他當時在睡覺。他立刻按右上角變更密碼，並把時間告訴系統管理員。

### 回報系統問題

1. 回到首頁，看歡迎列裡的「系統版本」與「執行環境」。
2. 連同發生問題的頁面、操作步驟、時間（以及錯誤追蹤碼，如果有）一起交給系統管理員。

**會得到什麼**：系統管理員能立刻判斷你用的是哪一版、哪一個環境，縮短查問題的時間。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **儀表板** | 首頁下方一張張的區塊卡片，各自顯示一類資訊；只出現你有權限看的。 |
| **快速入口** | 首頁上直接前往常用業務頁面的連結，只會列出你有權限進入的頁面。 |
| **上一次登入** | 倒數第二次成功登入的時間與方式（最近一次通常就是現在這次）。 |
| **錯誤追蹤碼** | 出錯時畫面上的一串代碼，系統管理員用它在日誌裡找到這一次的錯誤。 |
| **系統版本** | 目前系統的版本號與發布日期，回報問題時請一併附上。 |
| **執行環境** | 系統目前跑在開發（`Development`）還是正式（`Production`）環境；兩邊的資料互不相通。 |
| **通知鈴鐺** | 右上角的鈴鐺：全部通知都在這裡，「全部標為已讀」清掉紅色數字。 |

## 七、常見問題

**問：為什麼我看不到「排程作業」區塊？**
答：那個區塊只給管理員看。一般使用者只會看到「我的通知」與「我的帳號」。

**問：「上一次登入」為什麼不是剛剛那次？**
答：剛剛那次就是你現在正在用的登入；這裡顯示的是再之前那一次，用來發現不是你做的登入。

**問：某個區塊顯示「這個區塊暫時無法顯示」？**
答：那個區塊讀取時出錯，其他區塊不受影響。重新整理頁面；仍然發生時，把畫面上的錯誤追蹤碼告訴系統管理員。

**問：首頁顯示「你沒有權限存取此頁面」是怎麼回事？**
答：首頁本身也是一項可以授予的權限。請系統管理員在角色管理中替你的角色勾選「首頁」。

**問：登入後為什麼沒有停在首頁，而是直接到了別的頁面？**
答：如果你是先打開某一頁、被要求登入，登入成功後系統會帶你回到原本要去的那一頁；直接開登入頁登入時，才會預設來到首頁。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖），以及歡迎列裡的系統版本，回報給系統管理員。
