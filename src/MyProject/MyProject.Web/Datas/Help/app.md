# 首頁

登入後第一個看到的畫面，讓你**認識這套系統能做什麼**，並從**快速入口**直接前往常用的業務頁面。

### 一分鐘看懂這一頁

- **解決什麼問題**：剛登入時不知道系統有哪些功能、該從哪裡開始，這一頁用介紹卡片與快速入口替你整理好。
- **誰會用到**：所有登入系統的人；每次登入成功、或點側邊選單最上方的「首頁」都會回到這裡。
- **它在系統的哪個位置**：側邊選單最上方的「首頁」，是登入後的落地頁；變更密碼頁按「取消」或儲存成功後也會回到這裡。
- **開始前要準備**：不需要準備任何資料，只要已經登入；快速入口會依你角色的權限自動決定要顯示哪幾個連結。
- **做完會得到**：知道系統的主要能力，並能一鍵進入你有權限的專案項目、分類清單或團隊清單頁面。
- **它不做什麼**：首頁只是介紹與導覽，不能在這裡新增或修改任何資料，也不會顯示統計數字或待辦事項。

## 一、功能摘要

首頁由上而下分成四個區塊：最上方是系統名稱與系統描述；接著是「系統能力」六張介紹卡片；再來是「快速入口」連結；最底部是「系統版本」與「執行環境」。這一頁純粹用來介紹與導覽，不讀寫任何業務資料，所以每個人看到的介紹內容都一樣，只有快速入口會因權限而不同。

## 二、這個頁面在做什麼

系統介紹區塊顯示的名稱與描述，是系統管理員在設定檔裡設定的系統資訊，換了一套部署就可能不同。

「系統能力」的六張卡片只是文字說明，**不能點擊**，也不會帶你到對應頁面。它們分別介紹：權限與角色控管、專案項目管理、分類與團隊定義、日誌檢視與 AI 分析、健康監控與資料庫用量、檔案上傳與保管。其中「日誌檢視與 AI 分析」與「健康監控與資料庫用量」介紹的是管理員專用功能，一般使用者在側邊選單裡看不到它們是正常的。

「快速入口」會逐一檢查你是否有該頁面的檢視權限，只顯示你進得去的連結；如果三個都沒有權限，整個「快速入口」標題與區塊都不會出現。

最底部的「系統版本」與「執行環境」是回報問題時最有用的兩項資訊。

## 三、畫面上有哪些按鈕、各自做什麼

### 畫面區塊

| 區塊 | 內容 | 可以操作嗎 |
|---|---|---|
| 系統介紹 | 品牌圖示、「Welcome」字樣、系統名稱、系統描述 | 不可操作，純顯示 |
| 系統能力 | 六張介紹卡片，每張有圖示、標題與一段說明 | 不可點擊 |
| 快速入口 | 最多三個連結：「專案項目」、「分類清單」、「團隊清單」 | 點一下即前往該頁 |
| 版本資訊 | 「系統版本」與「執行環境」 | 不可操作，純顯示 |

### 快速入口的顯示條件

| 連結 | 前往的頁面 | 什麼情況下會出現 |
|---|---|---|
| 專案項目 | 專案項目清單 | 你的角色有「專案項目」的檢視權限 |
| 分類清單 | 分類主檔維護 | 你的角色有「分類清單」的檢視權限 |
| 團隊清單 | 團隊主檔維護 | 你的角色有「團隊清單」的檢視權限 |

管理員不受權限限制，三個連結一律顯示。

> **提醒**：「權限與角色控管」卡片的文字提到「檢視／新增／修改／刪除／匯出」五種動作，但目前角色權限只有檢視、新增、修改、刪除四種，「匯出」已經下架，角色管理畫面裡找不到這個選項是正常的。

> **提醒**：「執行環境」顯示 `Development` 代表開發或測試用的環境，顯示 `Production` 代表正式環境。在開發環境裡輸入的資料，不會出現在正式環境。

## 四、建議這樣操作，會得到什麼

### 情境一：第一次登入，想知道自己能做什麼

1. 登入後停在首頁，先讀「系統能力」六張卡片，了解系統的整體範圍。
2. 看「快速入口」出現了哪幾個連結，這就是你目前角色能進入的業務頁面。
3. 對照左側選單，確認選單裡看得到的項目與快速入口一致。

會得到：清楚知道自己的權限範圍；若缺少工作需要的頁面，可以直接請管理員調整角色。

### 情境二：回報系統問題

1. 回到首頁，捲到最底部。
2. 抄下「系統版本」與「執行環境」兩項。
3. 連同發生問題的頁面、操作步驟與時間一起交給管理員。

會得到：管理員能立刻判斷你用的是哪一版、哪一個環境，縮短查問題的時間。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| 快速入口 | 首頁上直接前往常用業務頁面的連結，只會列出你有權限進入的頁面 |
| 系統能力 | 六張介紹系統功能的卡片，純說明用，不能點擊 |
| 系統版本 | 目前系統的版本號與發布日期，回報問題時請一併附上 |
| 執行環境 | 系統目前跑在開發（`Development`）還是正式（`Production`）環境 |
| 檢視權限 | 角色被允許進入某個頁面的權限；沒有這個權限，選單與快速入口都不會出現該頁 |
| 管理員 | 帳號上被勾選為管理員的人，可以使用所有功能，不受角色權限限制 |

## 七、常見問題

**為什麼我的快速入口少了幾個連結，甚至整段不見？**
快速入口只顯示你有檢視權限的頁面。三個都沒有權限時，「快速入口」整個區塊會隱藏。需要使用哪一頁，請管理員替你的角色加上該頁的檢視權限。

**點「系統能力」的卡片為什麼沒有反應？**
這六張卡片只是功能介紹，本來就不能點擊。要前往某個功能，請使用左側選單或「快速入口」。

**首頁顯示「你沒有權限存取此頁面」是怎麼回事？**
首頁本身也是一項可以授予的權限。如果你的角色沒有「首頁」的檢視權限，就會看到這段紅色提示；請管理員在角色權限中勾選首頁。
