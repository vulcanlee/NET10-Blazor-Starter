# 團隊清單

維護「團隊」這份清單：**新增、修改、停用、刪除團隊**。團隊決定**誰看得到哪些資料**：專案可以指定團隊，只有該團隊的成員看得到；分類可以指定適用團隊；使用者與角色也可以綁定團隊。

> 團隊會影響資料的可見範圍，而且**改名、停用、刪除都不會自動同步**到已經使用它的專案與分類，動手前請先看第二段的說明。

### 一分鐘看懂這一頁

- **解決什麼問題**：不同小組的專案不想互相看到時，需要一個「小組」的單位來分權；這一頁就是用來建立與維護這些團隊。
- **誰會用到**：系統管理員，或負責組織架構與資料定義的人；一般同事只會在專案、分類的團隊下拉選用這裡建好的團隊。
- **它在系統的哪個位置**：左側選單「資料定義 › 團隊清單」；在流程上排在最前面：先建團隊，再到使用者管理、角色管理把人放進去，專案與分類才選得到它。
- **開始前要準備**：先想好團隊的正式名稱（建好後盡量不要改名），以及哪些同事要加入這個團隊。
- **做完會得到**：一個可在專案、分類、使用者與角色的團隊下拉中選到的團隊，用來限定專案的可見範圍與分類的使用範圍。
- **它不做什麼**：不能在這裡把人加進團隊（那是使用者管理或角色的預設團隊），也不會同步更新已經記錄在專案、分類上的團隊名稱。

## 一、功能摘要

在這裡可以做什麼：

- 新增、修改、刪除團隊（依你的權限顯示按鈕）。
- 用「啟用狀態」開關停用團隊；停用的團隊不會再出現在各處的團隊下拉選單中。
- 為團隊填寫選填的「代號」與「描述」。
- 輸入關鍵字搜尋團隊的名稱、代號與描述。
- 點表格欄位標題排序，用下方頁碼換頁（每頁 8 筆）。

## 二、這個頁面在做什麼

### 誰會使用、為什麼要用

| 角色 | 為什麼要用 |
|---|---|
| 系統管理員 | 建立與維護團隊，搭配使用者管理、角色管理決定每個人屬於哪些團隊。 |
| 資料定義負責人 | 依組織調整新增或停用團隊，讓專案與分類的團隊下拉保持正確。 |

### 團隊怎麼決定誰看得到資料

- 專案**沒有指定團隊** → 所有人都看得到（公開）。
- 專案**指定了團隊** → 只有屬於該團隊的使用者看得到。
- 使用者屬於哪些團隊＝在「使用者管理」直接綁定的團隊，**加上**他所有角色的「預設團隊」。
- 管理員看得到全部資料。

### 團隊是怎麼被記住的

專案、分類與角色的預設團隊，記錄的都是**團隊名稱這段文字**，不是代號；只有使用者管理裡「直接綁定」的團隊，是跟著團隊本身走的。這帶來三個容易踩到的後果：

| 動作 | 實際影響 |
|---|---|
| 改團隊名稱 | 使用者的直接綁定會跟著新名稱走；但專案、分類、角色預設團隊上記的**仍是舊名稱**，不會自動更新，可見範圍會悄悄出錯。 |
| 停用團隊 | 只會從各處的團隊下拉選單消失；已經屬於這個團隊的人**仍然看得到**它的資料，不能當成收回權限使用。 |
| 刪除團隊 | **不會有任何使用中的警告**；使用者的直接綁定會自動解除，但專案、分類、角色預設團隊上記的團隊名稱不會被清掉。 |

改「代號」則沒有上述影響，代號目前只是給人看的備註，不參與任何可見範圍的比對。

這份團隊清單本身不做團隊過濾：只要有權限進入這一頁，就會看到所有團隊，包含已停用的。

### 需要的權限

| 權限 | 可以做的事 |
|---|---|
| 檢視 | 進入畫面、搜尋與排序、看資料。沒有檢視權限時會看到「你沒有權限存取此頁面」。 |
| 新增 | 看得到工具列的「新增」按鈕。 |
| 編輯 | 看得到每列的「修改」按鈕。 |
| 刪除 | 看得到每列的「刪除」按鈕。 |

> 權限設定在「角色管理」權限設定的「資料定義管理功能 › 團隊清單」底下；管理員看得到全部。建議只把新增、編輯、刪除權限開給負責資料分權的人。

### 它跟其他頁面的分工

| 你想做的事 | 該去哪 |
|---|---|
| 建立、改名、停用或刪除團隊 | 這一頁 |
| 把某位同事直接加入團隊 | 「使用者管理」（系統管理員） |
| 讓擁有某角色的人自動屬於某些團隊 | 「角色管理」的預設團隊（系統管理員） |

## 四、建議這樣操作，會得到什麼

### 成立一個新團隊

1. 按工具列的「新增」，輸入正式的團隊名稱；需要時再填代號與描述。
2. 啟用狀態維持「啟用」，按「儲存」，在「確認儲存」選「儲存」。
3. 請系統管理員到使用者管理替成員綁定這個團隊，或在角色管理把它設為某角色的預設團隊。

**會得到什麼**：新團隊出現在專案、分類、使用者與角色的團隊下拉選單中，被綁定的成員可以看到指定了這個團隊的專案。

> 公司新成立「業務一組」。管理員先在這一頁新增團隊「業務一組」、代號 `SALES1`，再到使用者管理把王小明加入這個團隊。之後王小明建立專案「官網改版」時，團隊選「業務一組」，就只有同組的同事看得到這筆專案。

### 團隊要改名

1. 先到專案項目用「團隊過濾」找出掛了舊名稱的專案，記下清單；分類清單與角色的預設團隊也一併盤點。
2. 回到這一頁，在該列按「修改」，把名稱改成新名稱並儲存。
3. 逐一修改剛才記下的專案、分類與角色，把舊名稱換成新名稱。

**會得到什麼**：所有紀錄都改用新名稱，可見範圍維持正確，不會有資料因為名稱對不上而突然看不到。

### 團隊解散，不再使用

1. 在該列按「修改」，把啟用狀態切到「停用」並儲存。
2. 若要讓成員真的看不到該團隊的資料，請系統管理員到使用者管理與角色管理移除這個團隊的綁定。

**會得到什麼**：團隊不再出現在下拉選單中；搭配第二步，原成員也不再看得到只掛了這個團隊的專案。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| **團隊** | 系統劃分資料可見範圍的單位，專案指定團隊後只有該團隊成員看得到。 |
| **團隊名稱** | 各處用來比對可見範圍的文字，改名不會自動更新既有的專案、分類與角色。 |
| **代號** | 選填的短代號，目前只是備註，不影響任何可見範圍。 |
| **停用** | 讓團隊從下拉選單消失，但不會收回已綁定成員的可見範圍。 |
| **直接綁定** | 在使用者管理裡把團隊指定給某個人，這種綁定會跟著團隊改名，刪除團隊時會自動解除。 |
| **預設團隊** | 在角色上設定的團隊，擁有該角色的人會自動屬於這些團隊。 |
| **公開** | 專案沒有指定任何團隊，所有使用者都看得到。 |

## 七、常見問題

**問：我把團隊停用了，為什麼成員還看得到它的專案？**
答：停用只會讓團隊從下拉選單消失，不會收回可見範圍。要讓成員看不到，請系統管理員在使用者管理與角色管理中移除這個團隊。

**問：團隊改名之後，有些專案突然看不到了？**
答：專案上記的是舊的團隊名稱，改名後不會自動更新，所以原本的成員比對不到。請把這些專案的團隊改成新名稱，或把團隊名稱改回原本的名稱。

**問：代號要不要填？填了有什麼作用？**
答：代號是選填的，目前只是給人看或對外整合用的備註，不影響誰看得到哪些資料。有填時不可和其他團隊重複。

**問：刪除團隊前要注意什麼？**
答：刪除確認窗不會提醒你是否還有專案、分類或角色在用這個團隊，而且無法復原。請先用專案項目的「團隊過濾」盤點，不確定時改用「停用」。

**問：看不到「新增」「修改」或「刪除」按鈕？**
答：你的角色缺少「團隊清單」的對應權限（新增、編輯或刪除），請洽系統管理員調整角色。

**問：還是解決不了怎麼辦？**
答：請記下發生時間、操作的頁面與按鈕、畫面或右下角的訊息（最好截圖），以及右上角使用者選單「關於」裡的系統版本，回報給系統管理員。
