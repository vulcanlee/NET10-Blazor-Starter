# 團隊清單

維護「團隊」主檔：**新增、修改、停用、刪除團隊**。團隊是系統區分資料可見範圍的單位，決定誰看得到哪些專案。

### 一分鐘看懂這一頁

- **解決什麼問題**：建立一份統一的團隊名單，讓專案、分類、角色與使用者都能用同一組團隊來劃分資料的可見範圍。
- **誰會用到**：負責組織架構與資料定義的同仁或管理員；能不能新增、修改、刪除，依你角色的團隊清單權限而定。
- **它在系統的哪個位置**：側邊選單「資料定義」群組底下；這裡的團隊會出現在專案、分類、角色與使用者的團隊下拉選單中。
- **開始前要準備**：先想好團隊的正式名稱，名稱一旦被專案或分類使用，之後改名會造成比對失準，最好一次定案。
- **做完會得到**：一個可以在各處團隊下拉選單中選用的團隊，用來限定專案的可見範圍與分類的使用範圍。
- **它不做什麼**：不會把人加入團隊（那是使用者管理或角色的預設團隊），也不會同步更新已經記錄在專案、分類上的團隊名稱。

## 一、功能摘要

這一頁以清單呈現系統中所有團隊，每頁 8 筆，預設依更新時間由新到舊排序。你可以新增、修改、刪除團隊（依權限顯示），也可以用關鍵字搜尋名稱、代號與描述。每個團隊有名稱、代號、描述與啟用狀態；名稱必填且全系統不可重複，代號選填，有填時也不可重複，比對時都會忽略前後空白與英文大小寫。

## 二、這個頁面在做什麼

專案、分類與角色的預設團隊，記錄的都是**團隊名稱這段文字**，不是團隊代號。所以團隊名稱就是系統判斷「誰看得到哪一筆資料」的依據。只有使用者管理裡「直接綁定」的團隊，是跟著團隊本身走的。

這帶來三個容易踩到的後果：

| 動作 | 實際影響 |
|---|---|
| 改團隊名稱 | 使用者的直接綁定會跟著新名稱走；但專案、分類、角色預設團隊上記的**仍是舊名稱**，不會自動更新，可見範圍會悄悄出錯 |
| 停用團隊 | 只會從各處的團隊下拉選單消失；已經屬於這個團隊的人**仍然看得到**它的資料，不能當成收回權限使用 |
| 刪除團隊 | **不會有任何使用中的警告**；使用者的直接綁定會自動解除，但專案、分類上記的團隊名稱不會被清掉 |

改代號則沒有上述影響，代號目前只是給人看的備註，不參與任何可見範圍的比對。

這份團隊清單本身不做團隊過濾：只要有權限進入這一頁，就會看到所有團隊，包含已停用的。

## 三、畫面上有哪些按鈕、各自做什麼

### 工具列

| 按鈕／欄位 | 做什麼 | 何時出現 |
|---|---|---|
| 「新增」 | 開啟「新增團隊」對話窗 | 有團隊清單的新增權限才出現 |
| 「重新整理」 | 重新讀取清單，並顯示「已更新最新資料」 | 一律出現 |
| 「請輸入搜尋關鍵字」 | 輸入關鍵字，比對名稱、代號與描述 | 一律出現 |
| 「清空搜尋」 | 清掉關鍵字並回到第一頁 | 搜尋框有文字時才出現 |
| 「搜尋」 | 依關鍵字重新查詢並回到第一頁 | 一律出現 |

### 清單欄位

| 欄位 | 意思 |
|---|---|
| 名稱 | 團隊名稱，也是各處比對可見範圍的依據，可排序 |
| 代號 | 給對外整合或報表用的短代號，純備註，可排序 |
| 描述 | 團隊說明 |
| 啟用狀態 | 以徽章顯示「啟用」或「停用」，可排序 |
| 更新時間 | 系統自動記錄的最後修改時間，預設由新到舊排序 |
| 操作 | 每列的「修改」與「刪除」，固定在最右側 |

「修改」需要團隊清單的修改權限，「刪除」需要刪除權限，沒有權限的按鈕不會出現。刪除前會跳出「確認刪除」視窗：「確定要刪除這筆紀錄嗎？此操作無法復原。」，按「刪除」就會執行。

> **提醒**：刪除確認窗不會告訴你這個團隊是否還有專案、分類或使用者在用。刪除前請先自行確認，必要時改用「停用」。

### 新增／修改對話窗（團隊資料）

| 欄位 | 說明 |
|---|---|
| 名稱（必填） | 最長 100 字元，全系統不可重複；空白時顯示「團隊名稱 不可為空白」 |
| 代號 | 選填，最長 50 字元；提示文字為「請輸入團隊代號（選填，有填則需唯一）」 |
| 描述 | 多行文字，最長 2000 字元 |
| 啟用狀態 | 開關，顯示「啟用」或「停用」，新增時預設啟用 |

| 按鈕 | 做什麼 |
|---|---|
| 儲存 | 檢查欄位後跳出「確認儲存」視窗，選「儲存」才寫入、選「再檢查」回到表單。名稱或代號重複時，會顯示例如「團隊名稱已存在，無法新增。」或「團隊代號已存在，無法修改。」。修改時若沒有任何變更，顯示「沒有任何變更，未進行儲存。」並關閉視窗 |
| 取消（或右上角關閉、按 Esc） | 有未儲存的變更時，會問「尚有未儲存的變更」，選「放棄變更」關閉、選「繼續編輯」留下 |

## 四、建議這樣操作，會得到什麼

### 情境一：成立一個新團隊

1. 按「新增」，輸入正式的團隊名稱；需要對外整合時再填代號。
2. 啟用狀態維持「啟用」，按「儲存」並在「確認儲存」選「儲存」。
3. 請管理員到使用者管理替成員綁定這個團隊，或在角色管理把它設為某角色的預設團隊。

會得到：新團隊出現在專案與分類的團隊下拉選單中，被綁定的成員可以看到標記了這個團隊的專案。

### 情境二：團隊要改名

1. 先到專案項目用「團隊過濾」找出掛了舊名稱的專案，記下清單；分類清單與角色的預設團隊也一併盤點。
2. 回到這一頁，在該列按「修改」，把名稱改成新名稱並儲存。
3. 逐一修改剛才記下的專案、分類與角色，把舊名稱換成新名稱。

會得到：所有紀錄都改用新名稱，可見範圍維持正確，不會有資料因為名稱對不上而突然看不到或意外公開。

### 情境三：團隊解散，不再使用

1. 在該列按「修改」，把啟用狀態切到「停用」並儲存。
2. 若要讓成員真的看不到該團隊的資料，請管理員到使用者管理與角色管理移除這個團隊的綁定。

會得到：團隊不再出現在下拉選單中；搭配第二步，原成員也不再看得到只掛了這個團隊的專案。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| 團隊 | 系統劃分資料可見範圍的單位，專案掛上團隊後只有該團隊成員看得到 |
| 團隊名稱 | 各處用來比對可見範圍的文字，改名不會自動更新既有紀錄 |
| 代號 | 選填的短代號，目前只是備註，不影響任何可見範圍 |
| 停用 | 讓團隊從下拉選單消失，但不會收回已綁定成員的可見範圍 |
| 直接綁定 | 在使用者管理裡把團隊指定給某個人，這種綁定會跟著團隊改名 |
| 預設團隊 | 在角色上設定的團隊，擁有該角色的人會自動屬於這些團隊 |

## 七、常見問題

**我把團隊停用了，為什麼成員還看得到它的專案？**
停用只會讓團隊從下拉選單消失，不會收回可見範圍。要讓成員看不到，請管理員在使用者管理與角色管理中移除這個團隊。

**團隊改名之後，有些專案突然看不到了？**
專案上記的是舊的團隊名稱，改名後不會自動更新，所以原本的成員比對不到。請把這些專案的團隊改成新名稱，或把團隊名稱改回原本的名稱。

**代號要不要填？填了有什麼作用？**
代號是選填的，目前只是給人看或對外整合用的備註，不影響誰看得到哪些資料。有填時不可和其他團隊重複。
