# 角色管理

這一頁讓你**定義角色**，並用權限矩陣**勾選每個角色能進哪些頁面、能做哪些動作**，再替角色設定**預設團隊**。

> 這一頁只有管理員可以使用。

### 一分鐘看懂這一頁

- **解決什麼問題**：不必替每個人逐一設定權限，而是先把業務人員、主管這類職務做成角色，再把角色指派給人。
- **誰會用到**：負責權限規劃的系統管理員；一般使用者打開這一頁只會看到「你沒有權限存取此頁面」。
- **它在系統的哪個位置**：側邊選單「系統管理 › 權限管理」底下；這裡建好的角色，會出現在「使用者管理」表單的「角色」與「額外角色」選項裡。
- **開始前要準備**：列出這個職務需要用到哪些頁面、每一頁要能檢視、新增、編輯還是刪除，以及應該看得到哪些團隊的資料。
- **做完會得到**：一個可以指派給使用者的角色；擁有它的人會得到勾選的權限，並自動多出這個角色的預設團隊。
- **它不做什麼**：不能在這裡把角色指派給人（請到使用者管理），也無法授予系統管理底下各頁的權限，那些頁面只有管理員能進入。

## 一、功能摘要

- 新增、修改、刪除角色，並可重新整理清單。
- 以關鍵字搜尋角色名稱，清單預設依名稱排列，可點欄位標題排序。
- 在表單裡設定角色名稱與預設團隊。
- 用權限矩陣逐頁勾選「（全部）」或個別的「檢視」「新增」「編輯」「刪除」。
- 每一次新增、修改、刪除都會自動寫進稽核紀錄。

## 二、這個頁面在做什麼

本系統的權限分成三層：管理員、角色、團隊。這一頁負責其中的「角色」，同時也提供「團隊」的一部分來源：

| 層 | 這一頁的角色 |
|---|---|
| 管理員 | 與這一頁無關。管理員是使用者管理裡的勾選，會略過所有權限檢查，不需要任何角色 |
| 角色 | 權限矩陣決定擁有這個角色的人能做哪些動作。一個人有多個角色時，權限是**加總** |
| 團隊 | 「預設團隊」會**加到**每一個擁有這個角色的人身上，和他在使用者管理直接綁定的團隊合在一起，決定他看得到哪些資料列 |

清單上只看得到名稱與時間，預設團隊與權限都要按「修改」打開表單才看得到。

角色改完之後，擁有這個角色的人不必重新登入，下一次切換頁面或重新整理瀏覽器時就會套用新權限。

## 三、畫面上有哪些按鈕、各自做什麼

### 工具列

| 按鈕或欄位 | 做什麼 |
|---|---|
| 「新增」 | 開啟「新增角色」表單，權限矩陣全部未勾選 |
| 「重新整理」 | 重新讀取清單，右上角會出現「已更新最新資料」 |
| 搜尋框（提示字「請輸入搜尋關鍵字」） | 輸入關鍵字後按「搜尋」，比對角色名稱 |
| 「清空搜尋」 | 搜尋框有文字時才會出現，按下後清掉關鍵字並回到第一頁 |
| 「搜尋」 | 依關鍵字篩選清單，並回到第一頁 |

### 清單欄位與每一列的操作

| 欄位或按鈕 | 意思 |
|---|---|
| 名稱 | 角色名稱 |
| 建立時間／更新時間 | 系統自動寫入，不能修改 |
| 「修改」 | 開啟「修改角色」表單，帶出目前的預設團隊與權限 |
| 「刪除」 | 跳出「確認刪除」視窗（「確定要刪除這筆紀錄嗎？此操作無法復原。」），按「刪除」才會執行 |

### 表單：角色資料

| 欄位 | 說明 |
|---|---|
| 名稱 | 必填。與既有角色完全相同時會出現「角色名稱已存在，無法新增。」或「角色名稱已存在，無法修改。」 |
| 預設團隊 | 可多選，只列出啟用中的團隊。**留空代表這個角色不帶來任何團隊**（欄位提示是「選擇此角色可瀏覽的團隊（不設定表示僅能看到無團隊的公開紀錄）」） |

> **提醒**：預設團隊留空不是「不限團隊」，而是剛好相反。若使用者在使用者管理也沒有直接綁定團隊，他在專案項目就只看得到沒有標記團隊的公開紀錄。

> **提醒**：名稱重複的檢查只擋「完全相同」的名稱，大小寫不同或多了空白都會被當成不同的角色。

### 表單：權限設定（權限矩陣）

區塊說明寫著「勾選「全部」等於該資源的所有動作」。矩陣目前列出這些項目：

| 項目 | 可勾選的內容 |
|---|---|
| 首頁 | 一個勾選框，決定能不能進入首頁 |
| 專案管理功能 | 群組勾選框，底下是「專案項目（全部）」與四個動作 |
| 資料定義管理功能 | 群組勾選框，底下是「分類清單（全部）」「團隊清單（全部）」與各自的四個動作 |
| 登出 | 一個勾選框，決定側邊選單是否出現「登出」 |

每一頁的勾選方式：

| 勾選 | 效果 |
|---|---|
| 「（全部）」 | 等於該頁所有動作，包含日後系統新增的動作。勾了之後右邊四個動作會變成灰色不能點 |
| 「檢視」 | 能進入該頁、看到資料。**沒有勾「檢視」也沒有勾「（全部）」，就連頁面都進不去**，只勾「新增」或「編輯」沒有用 |
| 「新增」「編輯」「刪除」 | 各自允許對應的動作 |

勾選底下任何一項，上層的群組會自動跟著勾上。反過來，**取消勾選群組只會一併取消底下的「（全部）」，個別勾選的「檢視」「新增」「編輯」「刪除」會保留**，儲存後仍然有效。要完全收回某一頁的權限，請把那一頁的四個動作也逐一取消。

### 按下「儲存」之後

1. 名稱沒填會出現「名稱 不可為空白」。
2. 修改時一個字都沒改，會顯示「沒有任何變更，未進行儲存。」並直接關窗。
3. 跳出「確認儲存」視窗（「確定要儲存這筆記錄嗎？」），按「再檢查」可以回到表單。
4. 成功後顯示「新增成功」或「修改成功」。

按「取消」、關閉鈕或 Esc 時，如果表單有改過，會先問「尚有未儲存的變更」，可選「放棄變更」或「繼續編輯」。

## 四、建議這樣操作，會得到什麼

### 情境一：建立一個「只能看、不能改」的角色

1. 按「新增」，名稱填上容易辨認的職務名稱。
2. 在「專案管理功能」底下，只勾「專案項目」右邊的「檢視」，不要勾「（全部）」。
3. 勾選「首頁」與「登出」，讓對方有首頁可進、有登出可按。
4. 「預設團隊」選這個職務應該看得到的團隊，按「儲存」。

會得到：擁有這個角色的人看得到專案項目，但沒有新增、修改、刪除的權限。

### 情境二：讓整個部門多看得到一個團隊的資料

1. 找到這個部門共用的角色，按「修改」。
2. 在「預設團隊」加上新的團隊，按「儲存」。

會得到：所有擁有這個角色的人（不論是主要角色還是額外角色）下一次切換頁面時，就會看得到該團隊的資料，不必逐一修改使用者。

### 情境三：刪除一個不再使用的角色

1. 先到使用者管理，搜尋角色名稱，找出以它為主要角色的人，把他們的角色改成別的。
2. 回到這一頁按該角色的「刪除」，確認後重新整理清單，確定它已經消失。

會得到：角色被移除；原本把它當成額外角色的人，會同時失去這個角色帶來的權限與預設團隊。

## 五、名詞解釋

| 名詞 | 白話解釋 |
|---|---|
| 角色 | 一組權限加上一組預設團隊的組合，指派給使用者後才會生效 |
| 權限矩陣 | 表單裡「權限設定」那一整塊勾選表，一列是一個頁面，右邊是四種動作 |
| （全部） | 該頁所有動作的總開關，包含日後新增的動作 |
| 檢視 | 進入頁面並看到資料的權限，是其他動作的前提 |
| 預設團隊 | 擁有這個角色的人都會自動多出的團隊。留空代表這個角色不帶來任何團隊 |
| 權限取聯集 | 一個人有多個角色時，只要其中一個角色允許，他就能做。角色之間不會互相取消 |
| 管理員 | 使用者管理裡的特殊勾選，不是角色，也不受這一頁的設定影響 |

## 七、常見問題

**我在矩陣裡替系統管理底下的頁面找不到勾選項目，是漏了嗎？**
不是。使用者管理、角色管理、稽核紀錄、系統例外紀錄與統計分析各頁，刻意只開放給管理員，任何角色都勾不到。要讓某人使用這些頁面，只能在使用者管理把他設成管理員。

**按了「刪除」也顯示「刪除成功」，為什麼角色還留在清單上？**
最常見的原因是這個角色仍然是某些使用者的主要角色，系統不允許刪除正在被當成主要角色使用的角色。請先到使用者管理把那些人的「角色」改掉，再回來刪除。

**把某人的角色改掉之後，他要重新登入才會生效嗎？**
不用。對方下一次切換頁面或重新整理瀏覽器時，就會套用新的權限與團隊。

**新增使用者時，角色欄為什麼會自動帶入某一個角色？**
系統會預先帶入名稱為「預設角色」的角色。若你把它改名或刪除，新增使用者時就會改為帶入清單中的第一個角色。
